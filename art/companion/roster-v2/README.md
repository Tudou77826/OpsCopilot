# 八帧伙伴动作原稿与配方

使用内置 image_gen.imagegen，在七种既有角色的四帧动作原稿上分别补充中间姿态。完整提示词与参考图路径见 [prompts.json](prompts.json)。每份透明原稿为八列四行，依次包含待机、招呼、开心、休息。保持既有角色类型、配色、服饰与镜头，不重新设计角色。

```powershell
node tools/pixel/build-roster-motion.mjs
```

正式资源位于 `frontend-shell/src/companion/packs/<species>-v4`，每种 32 张 256×256 RGBA PNG，共 224 张、13,725,208 字节。三阶段共用原生帧，显示比例分别为 160/216、188/216、1，以脚底为缩放原点；不生成三份相同位图。只做明确的图集分割、噪点清理、对齐和保留软边缘的缩放，不进行颜色压缩或额外像素化。

主体水平中心由待机姿态确定，抬起的手臂不改变身体中心；同动作共用地面基线，保留真实离地高度。动作时间表按姿态声明，招呼选择方向一致的手臂或翅膀；招呼与开心只播放一次，结束后回到待机。

PNG 使用无损自适应编码压缩，解码后的 RGBA 与编码前完全一致。工具默认拒绝不同的已有资源，审查候选并明确替换时使用 `--replace`；原稿不覆盖。背景和奖章仍使用 lumen-v1，旧 v2/v3 角色包只保留历史复现来源，运行时使用 v4。

规格与校验见 [资源生产规范](../../../docs/companion-art-pipeline.md)，实测成本见 [性能验收](../../../docs/companion-performance.md)。

完整轮廓包含抬手、尾巴与跳跃位置，四边保留可见留白，锚点为 `(128,240)`；门禁检查轮廓边距，侧栏按视口和阶段适配画布，完整显示所有动作。
