# 伙伴角色原稿与配方

原稿使用内置 image_gen.imagegen 分别生成七种透明角色动作图集，完整提示词见 [prompts.json](prompts.json)。每份原稿为四列四行，依次包含待机、招呼、开心、休息四个关键姿态；原稿保持不变。

本目录的四帧历史配方为 `node tools/pixel/build-roster-detail.mjs`。分割原稿并按主体尺寸对齐，保留原始颜色层次和半透明边缘；使用预乘 Alpha 的双线性缩放，不再进行额外像素化、32 色量化或 Alpha 二值化。同动作共用地面基线，保留原稿跳跃的离地高度。生成 256×256 RGBA PNG，三阶段主体尺寸为 160、188、216 像素。

该历史版本资源为 `frontend-shell/src/companion/packs/<species>-v3`，每种 48 帧，共 336 帧、23,374,273 字节。运行时采用原色或保留明暗层次的色相变换；背景和奖章继续使用 lumen-v1。角色正常缩放，不强制最近邻放大。

动作声明逐姿态时长和重复路径：待机每 4.2 秒短眨眼，招呼交替挥手，开心使用原生离地姿态，休息放慢停留。四个关键姿态的数量没有增加，更细腻的肢体中间动作需要额外原生帧。隐藏、收起或减少动态效果时停止播放。

旧 `build-roster.mjs` 和 v2 低分辨率包仅保留历史复现配方，当前角色不使用该像素化流程。资源契约、体积上限与验收要求见 [资源生产规范](../../../docs/companion-art-pipeline.md)。

当前产品使用八帧 v4 角色包，原稿与正式配方见 [八帧动作素材](../roster-v2/README.md)。
