# Lumen v1 素材规格与来源

生成工具：Codex 内置 `image_gen.imagegen`。选定 AI 原稿保存于 `source/`；标准化配方为 `recipe.json`，审核图为 `review-approved.png`。以下为生成时使用的角色、网格、符号和背景要求，供下一套资源保持一致；生成结果仍需按实际图像裁切和审核。

## 角色

原创像素幻想伙伴 Lumen：圆润薄荷绿色身体、叶形耳朵、短肢、奶油色腹部、深海军蓝轮廓、胸前琥珀小光点和淡粉脸颊。固定正面偏侧视角与同一照明方向。幼年、成长、成熟持续保留身份特征，逐步增加身形和耳朵长度。

一张透明 PNG，8 列 × 3 行等大方格，每格一个完整角色，格间不接触。行依次为幼年、成长、成熟；列依次为待机两帧、开心两帧、招呼两帧、睡觉两帧。每对动作有轻微而可见的变化，同阶段比例一致。画面无文字、格线、场景或阴影底板，使用清晰像素块和有限色板。选定图集随后引用原图编辑为透明角色切图，保持角色、格位和姿势。

## 奖章中心图案

每次生成一个居中、独立、透明的低分辨率像素符号，保持约 24×24 的中心图案结构。使用深海军蓝、奶油白、薄荷绿、琥珀与深绿；清晰块状边缘，固定描边与光照。无文字、字母、数字、外框、场景、模糊、光晕或抗锯齿。标准化后中心符号为 20×20，放入代码生成的统一 32×32 盾形外框。

| 原稿 | 符号要求 |
| --- | --- |
| `knowledge-archive.png` | 归档书本，突出装订书脊与存放标识 |
| `script-created.png` | 脚本卷轴与清晰代码括号形状 |
| `quick-command-created.png` | 小终端卡片与提示符形状 |
| `case-completed.png` | 排查笔记本与勾选符号 |
| `knowledge-read.png` | 打开书本与放大镜 |
| `script-used.png` | 脚本卷轴与播放三角 |
| `quick-command-used.png` | 终端卡片与闪电 |
| `active-day.png` | 日历与单一完成标记 |

铜、银、金及未解锁四种边框由受控色板模板组合，保证符号和外框位置一致；类别名称和数量由界面显示。

## 背景

16:9 像素夜间空地，深蓝底色，薄荷与深绿树木位于两侧，下方草地，右侧小琥珀灯笼，少量奶油色星点。中央大面积留空，便于叠加伙伴；无角色、文字或界面。结果原图 1672×940，按配方明确裁切为 `[4,4,1664,936]`，再映射到 320×180 固定色板背景。

## 标准化与审核

运行 `tools/pixel/build-lumen.mjs` 读取原稿与配方。角色按 Alpha 连通身体去除孤立像素、二值化透明边缘，同阶段统一比例，以 `(32,56)` 对齐脚底；配色只替换色板，不生成新轮廓。原稿保持不变，正式包不包含原稿。

审核确认三个阶段身份一致，十二组动作帧互不重复、无孤立边缘像素，八类中心符号可区分，背景预留中心；正式包通过尺寸、Alpha、色板、动画、路径和体积门禁。实际页面验证包括三种配色、明暗主题、两种窗口宽度、动作播放及减少动态效果。
