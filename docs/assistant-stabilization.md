# 助手稳定化基线

状态：2026-10-21，本地验证；真实内网、Gauss 兼容和发行包交付仍待验收。

## 范围与结论

本基线包含首批受控终端、Chrys ACP/MCP 持续对话、数据库工作区交接、原生本地工具、Skills／Command 管理及对应交互。未扩展远程文件面板或增加插件运行平台。

当前对话显示记录与模型会话在同一应用进程中管理。页面重载撤销旧轮次及确认，等待取消收尾后恢复已接受消息与实际结束状态；不重放队列，不续跑旧操作。新建同时重置模型与显示记录，应用重启不恢复历史。显示记录按完整轮次限量保留，省略时明确提示。

## 审查重点

| 边界 | 实现与检查 |
|---|---|
| 会话与显示一致 | 后台记录实际接受的问题和结束结果；恢复不依赖浏览器缓存 |
| 取消与审批 | 按原轮次编号停止，等待子进程取消收尾，旧答案不能重新授权 |
| 异步恢复 | 初始化完成前禁止发送；失败可重试；页面卸载后的迟到响应失效 |
| 真正新建 | 忙时返回错误，后台成功后才清界面；同时回归模型上下文隔离 |
| 数据与体积 | 不保存队列、批准或表单凭据；历史驻留内存，超过上限移除完整旧轮次 |
| 输入区与浮层 | 状态／停止位于确认卡片下方；返回最新在按压和布局变化期间保持位置 |

显示历史不是模型上下文副本或操作审计。其消息上限不代表清除了模型记忆；真实命令、SQL 和原生工具仍分别使用既有授权与审计入口。恢复失败不等于旧轮次已经完全结束，界面不得据此自动重试命令。
