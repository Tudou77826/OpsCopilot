# v1.9.0.2

## 修复：批量下载大量文件时部分失败

批量下载会同时启动全部传输任务，同一 SSH 连接上并发打开的 SFTP 会话数超过服务端上限（sshd 默认 `MaxSessions 10`），超出的任务被服务端拒绝，造成「下了一批 log 文件，只有一部分成功」。

- 新增**单会话传输并发限制**（最多 4 个同时传输），超出的任务自动排队，排队中显示「排队等待其他传输完成...」，排队期间可正常取消；对 SFTP、SCP、root 直连、root 中转四种传输模式统一生效
- 并发超限类错误不再被误判为「未知错误」并触发注定失败的 SCP 重试，改为明确提示「并发传输过多，服务端拒绝新会话」
- 批量下载启动失败的文件在文件面板**汇总提示**，不再被最后一条错误覆盖；各任务的传输进度与成败仍在任务列表中逐项展示

## 修复：终端最后一行文字下缘被截断

部分分辨率下终端行高取整的亚像素误差会把最后一行字符的下伸部分（g/y/p 等字母的「小尾巴」）裁掉一小截：

- 终端容器底部内边距由 4px 增至 8px，最后一行整体上移、下方留出缓冲（与此前右边缘半字符裁切的修法一致）
