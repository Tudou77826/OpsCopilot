# OpsCopilot v1.12.0

本次更新新增数据库工作台，扩展了桌面助手可接入的 Agent，并更新了内网服务的运营首页。

## 数据库工作台

- 可在 OpsCopilot 中管理数据库连接、浏览库表和执行 SQL。访问内网数据库时，可通过 SSH 隧道连接。
- 新增 JDBC 驱动管理入口，可按需导入数据库驱动。Windows 完整安装包已包含 JDBC 运行组件。

## 桌面助手

- 支持在助手设置中选择 CodeAgent、OpenCode、iCode 或自定义 ACP Agent。
- 可以在助手对话中引用工作台页签。需要确认的操作会显示目标和内容，便于审批。
- 修复 `Ctrl+K` 面板的「生成」和「重新生成」按钮，鼠标点击和回车均可提交。

## 内网服务

- 未配置内网服务的桌面端启动后即可使用预设地址。已有自定义地址继续生效，使用数据仍按用户授权上报。
- 运营首页新增近 90 天累计活跃安装、今日与昨日活跃安装，以及近 30 天趋势。统计按授权安装去重，缺报日期单独标明。

## 其他更新

- 新增像素伙伴和功能奖章，可在「设置 → 高级选项」启用。绑定组织账号并选择参与后，可查看组织排名。
- 改进大文件分块传输，以及传输取消后的恢复。

## 下载与升级

Windows 用户可在客户端检查更新，也可下载完整的 `opscopilot-windows.zip`，解压后运行 `opscopilot.exe`。内网管理员如需启用新版运营首页，请先备份服务数据目录，再更新对应架构的 Linux 服务程序。
