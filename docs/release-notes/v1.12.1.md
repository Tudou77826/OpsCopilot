# OpsCopilot v1.12.1

快捷指令可以引用当前终端的信息，桌面助手也可以帮你新建并打开 SSH 连接。本公告同时包含 v1.12.0 的更新要点。

## 快捷指令

- 编辑快捷指令时，点「命令内容」旁的「插入变量」，可引用本地 IP、远程 IP、终端选中的一行文本和本地日期。已有指令也可以编辑后使用变量。
- 快捷指令面板预置「粘贴本地 IP」和「粘贴远程 IP」两个可编辑的按钮。点击时从当前终端取值，填到光标处，由你按回车执行。取不到值时会给出提示并保留原输入。

## 桌面助手

- 可以直接让 Agent 打开已保存的 SSH 连接。目标还没保存时，Agent 会预填新建连接表单，你可以在表单中补全凭据并保存，然后让 Agent 在同一轮继续打开终端。
- 会话栏右上角新增「?」。悬停可查看 OpsCopilot 提供的 SSH、终端、数据库、文件、本地项目和运维资料能力。

## v1.12.0 更新要点

- **数据库工作台**可管理数据库连接、浏览库表、执行 SQL，并通过 SSH 隧道访问内网数据库。Windows 完整安装包包含 JDBC 运行组件，也可按需导入驱动。
- **桌面助手**支持 CodeAgent、OpenCode、iCode 和自定义 ACP Agent，可在对话中引用工作台页签。修复了 `Ctrl+K`「生成」和「重新生成」按钮的鼠标点击。
- **内网服务**为未配置地址的桌面端提供默认地址。运营首页展示近 90 天累计活跃安装、今日和昨日活跃安装，以及近 30 天趋势，统计按授权安装去重。
- **其他更新**包括像素伙伴、功能奖章、组织排名，以及大文件分块传输和取消恢复改进。详见 [v1.12.0 公告](https://github.com/Tudou77826/OpsCopilot/releases/tag/v1.12.0)。

## 下载与升级

Windows 用户可在客户端检查更新，或下载完整的 `opscopilot-windows.zip`，解压后运行 `opscopilot.exe`。内网服务管理员如需启用新版运营首页，请先备份服务数据目录，再更新对应架构的 Linux 服务程序。
