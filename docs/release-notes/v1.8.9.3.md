# v1.8.9.3

## 修复

- 修复 Telnet 网络设备 CLI 中输入错误后无法退格删除的问题：NVT 模式下将 DEL(0x7f) 转为 BS(0x08)、独立的 CR 转为 CRLF，适配擦除键为 Ctrl-H 的网络设备；自动登录凭据改用 CRLF，并收紧读超时消除超时竞态（#60）。
- 重复按 Ctrl+F 会重新触发搜索面板并复位到左下角，修复此前面板打开时仅聚焦输入框、不归位的问题。
