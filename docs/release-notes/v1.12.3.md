# OpsCopilot v1.12.3

本次更新重点增强了数据库工作台的查询结果交互、SQL 编辑器快捷键与数据库连接配置体验，同时加固了智能连接解析与明亮主题对比度。

## 数据库工作台

- **查询结果区交互升级**：支持多格/多行拖拽选择、`Ctrl+A` 全选、`Ctrl+C` 矩阵复制、结果内快速筛选、点击列头排序、右键菜单复制/导出（CSV / TSV / JSON / INSERT），以及居中单元格详情弹窗（支持自动换行与 JSON 格式化）。
- **结果表格直接编辑**：可写连接下支持双击单元格就地编辑（多行内容直接进入详情编辑），修改先暂存高亮，可在结果工具栏一键确认提交 `UPDATE`、复制 SQL 或全部撤回。
- **SQL 编辑器增强**：修复行尾按 `Ctrl+Enter` 误执行下一条语句的问题；新增 `Ctrl+Alt+L` / `Shift+Alt+F` 格式化 SQL、`Ctrl+Y` 删除当前行快捷键，以及高对比度的自动补全弹窗。
- **连接配置与界面精简**：左侧浏览器顶栏新增「定位当前连接」按钮；编辑连接时将连接名称与标记移至基础页并直接回显密码，复制连接时自动带出密码；移除多余顶部上下文栏并优化下拉控件与标签页样式。

## 智能连接与主题

- **智能分析凭据清洗**：自动剥离从文档或聊天窗口复制连接信息时混入的零宽字符、BOM、换行及首尾空白，保留密码中间字符，并自动补齐缺失的默认端口（含跳板机），减少认证失败。
- **明亮主题对比度优化**：提升明亮主题下终端配色、关键词高亮与面板层次的清晰度。

## 下载与升级

Windows 用户可在客户端检查更新，或下载完整的 `opscopilot-windows.zip`，解压后运行 `opscopilot.exe`。
