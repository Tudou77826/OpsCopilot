# v1.9.0.3

## 新增：文件传输队列易用性增强

- **全量进度**：传输队列头部新增聚合统计（共 N · ✓ 完成 · 传输中 · 排队 · ✗ 失败）与一条总进度条（完成数/总数 · 百分比），批量传输大量文件时不再需要逐个数任务
- **文件名展示**：任务行显示文件名（悬停看全名），替代此前无意义的任务 ID 前缀
- **队列高度可调**：队列顶部新增拖拽手柄，按住拖动调整高度（120px ~ 面板 60%），双击恢复默认；高度持久化，重启后保留
- **尊重隐藏意图**：用户隐藏队列后，任务完成事件不再强制弹出队列面板（此前批量传输会被逐个弹回）；隐藏期间有任务失败时，顶栏按钮显示「显示队列 (N 失败)」徽标提示
- **对齐布局**：任务行改为四列网格（文件名 | 状态 | 详情 | 操作），行行对齐；状态汉化（✓ 完成 / ✗ 失败 / 已取消 / 排队 / 传输中），字节进度与速度合并为一列
- **清空已完成**：一键清理已完成/已取消的任务，失败任务保留供查看

## 修复

- 修复任务开始传输后仍显示「排队等待其他传输完成...」的问题：字节进度事件现在显式清除排队提示，任务状态实时切换为「传输中」并显示字节进度与速度
- 修复 root 直连模式下每次上传/下载预检泄漏一条 SSH 连接的问题（批量传输 N 个文件泄漏 N 条连接）
