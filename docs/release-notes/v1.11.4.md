# v1.11.4

## 内网服务支持手工发布版本

- 管理后台新增“版本与安装包 → 上传新版本”。管理员可以从浏览器上传 Windows 更新 ZIP、更新说明，以及可选的独立 EXE 和 Linux 服务程序。服务器无需访问 GitHub 下载地址。
- 安装包上传完整并通过格式、大小和 SHA-256 校验后，版本才会出现在客户端更新检查与门户下载区。已发布版本不能覆盖；GitHub 同步不会把手工发布的新版本回退。
- 后台区分手工上传与 GitHub 同步的版本，并显示客户端当前可获取的版本。

**部署提示：**先将本次 Release 中与服务器架构匹配的 `opscopilot-service-center-linux-amd64` 或 `opscopilot-service-center-linux-arm64` 更新到内网服务器。然后从能够下载 Release 附件的电脑打开内网管理后台，上传 `opscopilot-windows.zip`，版本号填写 `v1.11.4`。若使用反向代理，请允许 1 GB 上传并适当延长发送超时；仓库的 Nginx 示例已更新。客户端无需重新配置内网地址。
