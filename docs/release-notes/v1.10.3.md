# v1.10.3

## 修复

- **SCP 降级会话也支持远端文件浏览**：对端没开 SFTP 只有 scp 时，文件面板的远端一侧不再是"填路径"表单，与其他连接一样支持目录浏览、重命名、删除、新建、在线编辑；操作以登录用户身份执行，权限与传输本身一致
- Root 密码不再丢失：新建连接或连接成功时保存的 root 密码，此前打开编辑弹窗显示为空、从会话树双击连接也不带（sudo 提权失效），只改个名字保存还会把已存的清掉——已修复，编辑、连接、再保存全链路完整保留
- 主机密钥校验恢复：从会话树连接时此前会丢掉已固定的主机密钥，退回不校验状态；现已随连接生效
- 连接改名、移动分组后重连，名字和位置不再被还原
- telnet 连接真正以 telnet 协议连接（端口 23），此前一律按 SSH 连导致失败
- 智能分析识别 `IP 用户名 密码` 平铺写法时，含 @ 的用户名（如 `accon@123`）不再被拆错
- 断线重连后终端串屏（#74）
- 切换终端标签后文件面板跟随切换（#72）
- 文件面板空白处右键菜单可用（#73）
- 跳板机提权失败时明确报错，不再静默按普通用户继续，导致文件面板权限显示与实际传输不一致（#75）
- 修复 35 处文字对比度不足，暗色模式可读性改善

## 新增

- **文件夹整体上传 / 下载**：目录支持右键或拖拽上传/下载，整个文件夹连同子目录一次传完
- **目录合并传输**：远端已有同名文件夹时提示确认，合并后同名文件覆盖、其余保留
- **传输失败清单**：个别文件失败不影响其余，完成后列出失败明细，可补传
- **传输上限提升**：跳板机场景单文件上限从 300KB 提升到 10MB
- **「全部覆盖」**：批量传输遇到同名文件可勾选跳过逐个确认，本批直接覆盖
- **传输提示可读**：完成提示显示「SFTP · Root 直连」等实际方式，不再显示内部代号
- **快捷命令「发送广播」**：命令卡右键直达广播，无需先切广播模式
- **Windows 风格皮肤**：设置 → 外观 可切换，带预览
- **插件明暗跟随宿主**：iCode Teams 内自动跟随宿主明暗，手动选择的主题不被覆盖

## 已知边界

- SCP 降级模式的会话暂不支持文件夹传输（会明确提示）
- 跳板机文件夹传输要求单个文件不超过 10MB
- 快捷命令导入只支持"发送字符串"类型的按钮
