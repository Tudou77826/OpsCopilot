# v1.9.0.1

## 新增：关于页更新体验增强

- 检测到更新时，新版本卡片头部显示「落后 N 个版本」警示徽标（落后 2 个版本及以上才提示，悬停查看当前/最新版本明细），让长期未更新的用户明确知道自己落后的程度
- 「AI 总览」：落后多版本时，新版本卡片头部出现 AI 总览入口，一键把自当前版本以来的全部更新说明（多版本累积日志）交给 AI 整合成一张**更新总览卡片**——按新功能/问题修复/体验优化分组、每条标注来源版本、合并同类项、去除内部术语；使用用户配置的快速模型，禁用思考、流式输出（带光标），生成后可重新生成或关闭
- 总览卡片与单版本卡片共用同一卡片体系（同宽度/高度/叠卡效果/翻页箭头），作为卡片组第一张插入，可左右翻页对照逐版本详情
- 检查更新后自动补全版本日志：卡片组直接呈现全部历史版本可翻页（此前只有最新一张，需手动点「更新日志」）
- 页脚「重新生成」改为明确的按钮形态并右对齐，与 AI 说明文案视觉分离

### 修复

- 修复「关于」页 loading spinner 动画从未生效的问题（`about-spin` keyframes 定义缺失）
- 修复落后版本统计的闭包缺陷：生产环境中徽标与 AI 总览入口会因捕获到未就绪的版本号占位符而永不出现
