# v1.9.0.4

## 新增：快捷命令面板易用性大改版

- **3D 滚筒分组切换**：右侧分组条升级为轻量 3D 滚筒——布局、宽度、风格与旧版一致，静止时仍是"蓝卡 + 上下灰字"的低干扰形态，滚轮/点击切换的瞬间卡片沿圆筒摆动换位、近大远小，停稳后回归平静
- **滚轮手感修复**：切换阈值 150→50（旧版偏钝）；修复三处"滚了没反应"——反方向滚动要先抵消旧累计、边界处继续同向滚导致累计堆积、很久以前的残留累计被误触发；滚轮时光标停留的前卡不再弹悬停提示
- **拖拽排序**：命令卡支持按住拖动调整顺序（当前分组内），拖动中源卡半透明、目标卡边缘显示插入位置指示线；搜索过滤时禁用（过滤结果的顺序无意义）；排序经意图化接口持久化，多窗口热加载同步
- **面板尺寸可调**：面板上边缘拖动调高度（96~400px）、分组条左侧分隔线拖动调宽度（56~140px，分组卡随之变宽），均持久化记忆；命令区滚动边界跟随面板实际高度
- **字体调大**：命令卡与分组卡字号提升至 12px

## 修复：新建分组流程打通

- 从分组条「+」新建分组时**直接进入分组名输入模式**（此前显示下拉框，必须先切到其它分组再切回「新建分组」才能看到输入框）
- 移除失焦陷阱：分组名输入框不再因点到其它字段而静默消失，改为显式「✕」按钮返回选择已有分组
- 分组名留空时禁用保存（含初始占位值绕过空判断的漏洞），避免命令被静默塞进第一个分组
- 此模式下弹窗标题纠正为「新建分组」；保存后自动切换到新分组，新命令立即可见
