# v1.10.0

## 新增：从 Xshell 导入会话

- **导入 Xshell 的会话导出**：支持三种形态——Xshell 导出的 `.xts` 备份包、单个 `.xsh` 会话文件、包含 `.xsh` 的目录树。分组层级按 Xshell 的目录结构逐层还原为嵌套文件夹，同名文件夹自动合并到根层级。
- **密码一并导入**：解密 Xshell 存储的会话密码，导入后可直接连接，不需要逐条重输。密钥规则已在本机 Xshell 8.1 上实测核对：`SHA256(reverse(SID) + Windows账户名)` + RC4，密文尾部 32 字节为 SHA256 校验和。
- **自动检测本机 Xshell 会话目录**：同机场景下无需用户去 Xshell 做任何导出操作，一键识别 `NetSarang Computer\<版本>\Xshell\Sessions` 并默认选中；这条路径也绕开了 `.xts` 可能被主密码整包加密的问题。
- **导入引导**：内置分步图文指引（文件 → 导出 → 选择目标位置 → 下一步 → 完成），因为多数用户不知道 Xshell 的导出入口在哪。指引同时提醒导出文件包含服务器密码、请勿随意外发。
- **先分析后导入**：写入前先给出预览——将导入多少条、多少条已存在会被跳过、多少条密码成功解密。密码解不开时明确说明原因（密钥依赖导出那台电脑的 Windows 账户标识）并说明这些会话仍会导入、密码留待手工补充，而不是导完才发现密码是空的。
- **冲突处理**：遇到已存在的同主机同端口同协议会话一律跳过并计入报告，不改动已有会话的任何字段。

## 新增：多层嵌套文件夹管理

- **任意深度嵌套**：新建子文件夹、跨层拖拽移动、重命名、删除，层级不设上限。
- **拖拽排序**：按行高三分区落点——上缘插到该行之前、下缘之后（同级调整顺序），中间落在文件夹上则移入。文件夹自身也可拖动。
- **按名称排序**：右键文件夹或空白处可一键按名称排序（中文按拼音序，文件夹在前）。
- **环检测**：把文件夹拖进自身或其后代会被拦下并显示禁止光标，不会形成脱离根节点的环。
- **展开状态记忆**：打开/折叠的文件夹在重启后保持；搜索时自动展开命中项的祖先链；深层节点显示完整路径提示。
- **删除前告知影响**：删除文件夹时提示会同时删除其中多少个连接。

## 新增：新建连接（不建立会话）

- 右键空白处或任意文件夹可「新建连接」，把连接信息先存好，需要时再双击打开。此前只能"连一次"才能让连接进入列表，改密码或改端口得先连上再编辑。
- 新建时可指定保存到当前文件夹，保存后立即出现在该文件夹下。

## 变更：会话管理交互与数据

- **文件夹改名不再影响其中的会话**：分组改为按内部标识关联，重命名文件夹后其下所有会话保持原位。此前分组按名称关联，改名会让子会话的分组信息失配。
- **拖拽顺序会被保存**：此前列表每 5 秒按名称重新排序一次，用户拖出来的顺序会被下一次刷新抹掉。
- **文件夹列表不再每 5 秒闪动刷新**：改为操作后刷新与切回窗口时刷新，手动折叠的文件夹不会被动展开。
- **编辑连接弹窗移除了「分组」输入框**：会话归属由在树里的位置决定，拖动即移动。避免"填了分组但位置没变"这类不一致。
- **删除文件夹会连带删除其中的连接**，确认框会写明数量。

## 修复：历史数据的分组信息修正

- 打开应用时会对 `sessions.json` 做一次一致性对账：修正文件夹内外不一致的分组信息、补全缺失的标识、清理非法字段组合。**对账前会自动备份**为 `sessions.json.bak-<时间戳>`，可随时回退。用户可见的层级、名称与顺序不受影响。
- 会话文件改为原子写入（临时文件替换），写入中途崩溃或断电不再产生被截断的 `sessions.json`；内容没有变化时不重复写盘。

## 修复：导入预览导致界面黑屏

- 点击「分析并预览」后整个界面变空。原因是后端返回的空集合是 `null` 而不是空数组/空对象，界面按数组处理时抛异常，而 React 的渲染异常会卸载整棵组件树——一处出错导致整个应用不可用。现在导入结果里的集合字段一律返回空集合，界面同时做了容错。
- 新增界面错误边界：今后任何面板的渲染异常只会让该面板显示错误原因并允许重试，不再连带整页白屏。

## 重构

- 会话存储层 `pkg/sessionmanager` 更名为 `pkg/connectionstore`，与运行态会话的命名歧义消除；文件夹相关接口全部改为按内部标识寻址。
- Wails 与 sidecar 两端的会话接口统一改用 `(T, error)` 返回约定，不再依赖"返回字符串里是否包含某段文案"判断成败；两端能力集对齐（sidecar 补齐了复制连接）。
- 会话管理界面按职责拆分（纯逻辑模型 / 数据与状态 / 树渲染与拖拽 / 右键菜单 / 属性弹窗 / 导入弹窗），并复用项目已有的命名对话框与通用右键菜单，删除两处自造实现。
- 新增 `internal/atomicfile`，并收敛仓库中另两处相同模式的重复实现。

## 已知边界

- 跨机器导入时，若拿不到导出那台电脑的 Windows 账户标识或 Xshell 主密码，密码无法解密（这是 Xshell 的密钥派生方式决定的）。界面会说明原因并支持填入源机器 SID 或主密码后重试。
- 使用密钥认证（而非密码）的 Xshell 会话，导入后会提示需要手工补充密码。
- Xshell 的代理/跳板配置存放在独立文件中，不随会话导出，导入时只提示、不自动映射。
