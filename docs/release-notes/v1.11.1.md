# v1.11.1

## Linux 内网服务端程序

Release 新增两个可直接运行的服务端程序：

- `opscopilot-service-center-linux-amd64`：通用 x86-64 Linux 服务器。
- `opscopilot-service-center-linux-arm64`：ARMv8.0 及更新的 64 位 Linux 服务器。

程序静态构建并内置门户和管理页面。服务器无需安装 Go、glibc 或独立数据库；仍需配置内网 HTTPS 反向代理、可写数据目录，并允许服务访问 GitHub 发布资源。

启动时必须设置 `OPS_SERVICE_PUBLIC_URL`（客户端访问的 HTTPS 根地址）和 `OPS_SERVICE_ADMIN_TOKEN`（至少 32 字符的随机管理员令牌）。建议用 `OPS_SERVICE_DATA` 指定持久化数据目录；默认监听 `127.0.0.1:9080`，可通过 `OPS_SERVICE_LISTEN` 调整。`OPS_SERVICE_GITHUB_TOKEN` 可选。完整说明见 [内网服务中心部署文档](https://github.com/Tudou77826/OpsCopilot/blob/v1.11.1/docs/intranet-service-deployment.md)。

本次桌面客户端功能与 v1.11.0 相同，版本号更新为 v1.11.1。
