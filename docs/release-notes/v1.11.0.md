# v1.11.0

## 新增：内网服务中心

- 可独立部署在内网，提供产品介绍、帮助、公告、反馈、版本同步与下载，以及运营数据管理页面。
- 配置服务地址后，客户端从内网服务查询和下载更新；安装前校验安装包。设置页可直接测试连接，并提供产品介绍、帮助和反馈入口。
- 首次使用前明确征求数据上报同意；可选常规上报、最简上报或完全关闭，并可随时在设置中调整。仅上报说明中列明的范围，不上传操作内容、命令参数、搜索词、文件路径或终端输出。
- 底栏公告与使用提示在同一位置交替轮播，公告有明确标识；同时增加产品介绍和反馈入口。服务端统计页面展示获授权的使用计数、升级结果及可观测的上报方式分布。

## 改进与修复

- CLI 增加面向 Agent 的知识库检索入口，并更新 OpsCopilot Skill；未识别的 CLI 参数现在会明确报错。
- 修复知识文档场景行号偏移、文件面板传输后目录跳转、终端字号切换后的末行裁切、连接属性表单被后台刷新清空等问题。
- 增加关键业务链路的仿真端到端测试。
- 改善 Windows 多进程争用配置文件锁时的等待时间，避免高负载下漏记已授权的使用计数。
