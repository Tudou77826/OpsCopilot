# v1.9.1

## 修复：终端会话健壮性

- **重连后残留旧全屏状态**：上一会话在全屏程序（vim/less/top）中断线时，备用屏、应用光标键、鼠标上报、括号粘贴等终端模式残留，导致新会话滚动条消失、提示符卡在屏中部（#67），滚轮被翻译成 `^[OA`/`^[OB` 误发给远端（#65）。重连成功后、新会话数据到达前，向本地终端写入模式复位序列，一次退出备用屏并失活全部残留私有模式
- **连接瞬间首帧输出偶发丢失**：后端按会话缓冲连接后的首个输出帧，待前端终端挂载完成再按原序放行；慢网络或服务器立即输出横幅时，终端首屏不再空白
- **SFTP 握手致界面卡死**：为 SFTP 握手增加超时保护，不支持 SFTP 的服务器不再拖住整个应用
- **终端搜索 Esc 作用域**：按 Esc 只关闭当前窗口的搜索框，不再连带关闭弹层
- **拖拽边缘自动滚动**：会话树与标签条拖拽到屏幕边缘时自动滚动，长列表拖放更顺手

## 修复：会话管理与共享 UI

- **保留完整配置**：编辑已保存会话时保留 root 密码等字段，修复边界场景下保存后被清空的问题
- **复制会话**：右键会话新增「复制会话」，可基于当前连接一键创建相似会话
- **交互细节修复**：拖拽文件夹不再误触发"移出分组"；编辑弹窗内点击不再冒泡到遮罩关闭
- **主题统一**：全端统一暖色浅色主题，跨宿主机表现一致

## 新增：密码明文显示

- 连接表单（密码 / Root 密码 / 跳板机密码）与设置（LLM API 密钥、共享密钥）的密码框全部改为明文显示。内网专用工具不再依赖浏览器原生"小眼睛"（WebView 各版本上显示不稳定、不明显），密钥直接可读可核对
