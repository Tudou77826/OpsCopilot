# v1.8.9

## 更新内容

- 设置页左上角新增「← 系统设置」返回入口，贴近左侧导航区，无需再跑到右下角退出。
- 快捷命令栏新增搜索卡片，可在当前分组内按关键字过滤命令（名称/内容匹配，大小写不敏感）。
- Skill 安装支持多个目录，支撑多个 coding agent（Claude Code / Cursor / Codex 等）并用；兼容旧版单目录配置。
- 连接失败时关闭错误弹窗会回到连接配置界面并带回失败的配置，便于修改后重试；重连失败仍留在原会话。
- AI 解析连接描述成功后保留输入框文本，方便改错重试，不再清空。
- 规则高亮默认改为大小写不敏感（error/Error/ERROR 都能高亮），`(?i)` 前缀仍兼容。
- 修正快捷键说明中 Ctrl+V 的误导文案（实际可用）。
- 修复 4 个遗留测试失败（timeline 断言文案、Sidebar 缺少 ToastProvider）。
