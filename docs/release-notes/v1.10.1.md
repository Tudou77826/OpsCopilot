# v1.10.1

## 新增：文件夹整体上传 / 下载

- 文件传输里，目录可以右键或拖拽直接上传/下载了，整个文件夹连同子目录一次传完
- 远端已有同名文件夹时默认合并：同名文件覆盖，其余保留，传之前确认一次
- 个别文件传失败不影响其余，完成后列出失败清单，补传即可
- 跳板机场景要求单个文件不超过 10MB，超限会提前列出，不会传一半才失败
- 顺带修复：单文件下载此前可能进度异常或报"文件不存在"，已修复

## 新增：传输体验

- 跳板机场景单文件传输上限从 300KB 提升到 10MB
- 传输完成提示改为可读文案（如「SFTP · Root 直连」），不再显示内部代号
- 批量传输遇到同名文件，确认框可勾选「全部覆盖」，本批不再逐个询问

## 新增：快捷命令「发送广播」

- 命令卡右键新增「发送广播」：广播开启时发给广播组，未开启时发给全部终端

## 修复：改名和分组被重连"改回去"

- 连接改名、移动分组后重连，名字和位置不会再被还原；密码变了只更新密码，其余不动

## 修复：智能分析

- 写明 telnet 的连接现在真正以 telnet 协议连接（端口 23），此前一律按 SSH 连导致失败
- 优化账号密码识别：`IP 用户名 密码` 平铺写法中，含 @ 的用户名（如 `accon@123`）不再被错误拆分

## 修复：终端与文件面板

- 断线重连后终端不再串屏（#74）
- 切换终端标签后，文件面板跟随切换（#72）
- 文件面板空白处右键菜单可用（#73）

## 新增：主题与皮肤

- 新增 Windows 风格皮肤（设置 → 外观，带预览）
- iCode Teams 内的插件自动跟随宿主明暗模式，手动选择的主题不被覆盖
- 修复 35 处文字对比度不足，暗色模式可读性明显改善

## 实验功能：养成花园

- 趣味养成玩法，默认关闭；在 设置 → 实验功能 中开启，随时可关

## 已知边界

- SCP 降级模式的会话暂不支持文件夹传输（会明确提示）
- 快捷命令导入只支持"发送字符串"类型的按钮，脚本/菜单类不可导入
