# v1.10.1

## 新增：从 Xshell 导入快捷命令

- **一键导入本机 Xshell 的快捷按钮**：自动探测 `<版本>\Xshell\QuickButton Files` 目录，无需在 Xshell 里做任何导出操作。也可手动选择单个 `.qbl` 文件或包含 `.qbl` 的目录。
- **落点参考 OpsCopilot 现状**，而不是只看导入的东西：
  - 分组不再靠手打：点开集合分组或逐条分组就是全部现有分组，逐条另可选「跟随集合」，需要新分组时走「＋ 新建分组…」再输入。清单只在选择器里出现，不在别的页面重复列一遍。
  - 还没有任何快捷命令时，来源页说明"导入时会新建分组"。
  - 某套按钮里若有命令的内容已经存在于某个分组，**默认落点就取那个分组**——不会给本该进「普通运维」的命令凭空新建一个分组。
  - 逐条标出所在位置：分组、名称、内容都相同标「已存在」（会跳过）；只有内容相同（名称不同）标「已在某分组」，提示它其实已有对应命令，可取消勾选或改名称对齐。
- **导入前先看清会发生什么**：预览只给三个数字——将导入、已存在（跳过）、类型不支持（跳过），并随你的改动**实时**重算。
- **粒度到单条命令**，三层都可以改：
  - 集合级：勾选要导哪几套按钮；每套填一个默认分组。两套填成同一个名字即合并，填不同即分开。
  - 命令级：逐条勾选（含全选、全不选、收起展开）。类型不是「发送字符串」的按钮（脚本、菜单等）仍然列出来，但置灰加删除线并写明原因，不可勾选。
  - 字段级：逐条改名称、改命令内容；逐条覆盖目标分组（默认跟随所属集合），因此一套按钮可以拆到多个分组。
- **「已存在」按最终归属实时判定**：它取决于目标分组，所以改集合分组、改单条分组、改名或改内容之后会立即重算——换了分组就不再算重复。预览给出的数字与点下去实际写入的结果一致。
- **确认按钮带条数**：「确认导入 N 条」；一套都没勾选时禁用。
- **按钮多的导出不会糊成一片**：超过 8 条的集合默认收起（条数与落点提示仍在集合头上），展开后逐条列表有高度上限并内部滚动；没有按钮的集合直接说明"没有可导入的命令"，不再摆一个空列表和用不上的按钮。
- **分组命名由你定**：默认 `Xshell`，输入框旁实时提示是新建分组、追加到已有分组，还是与本批其它集合合并。因为分组本身不支持重命名，命名权放在写入之前。
- **重复导入是幂等的**：目标分组内已存在同名同内容的命令会被跳过并计入报告，重复导入同一份 `.qbl` 不会把命令库堆成重复项。

## 变更：快捷命令存储

- `quick_commands.json` 改为原子写入（临时文件 + 替换）。导入会一次性写入整个命令库，此前的直接覆写一旦中途失败会丢掉全部快捷命令。

## 修复：导入预览的行内条数显示为 0

- 预览中每个集合那一行显示成"可导入 1 / 共 0 条"。该行的按钮数没有被填值，界面统计卡片上的总数却是对的，因此两个数字互相矛盾。

## 修复：导入完成后看不到结果报告

- 导入成功后弹窗跳回来源步，用户只看到一条提示，看不到本次写入了什么、跳过了多少。原因是弹窗的流程重置依赖宿主适配器对象，而该对象会随外层渲染被重建，导入触发的状态更新正好触发了这次重建。

## 重构

- `pkg/sessionimport` 更名为 `pkg/xshellimport`。该包现在同时承载会话（`.xsh` / `.xts`）与快捷命令（`.qbl`）两类 Xshell 落盘格式的解析，原名与会话绑定，已不准确。
- 会话导入与快捷命令导入共用的对话框外壳、分区、统计卡片与提示列表抽到 `ui/common/ImportParts.tsx`，两处不再各写一遍。
- Xshell 数据目录的探测（`Documents` / `OneDrive\Documents` / `OneDrive\文档` 三种根目录）抽成共用实现，会话目录与快捷按钮目录共用同一套枚举与版本排序；根目录作为入参，目录探测逻辑现在可以脱离真实用户目录被测试。

## 新增：文件夹整体上传 / 下载

- **目录可以整个传了**：此前只能选中一个一个文件传，现在对目录右键「上传」「下载」、或者把目录直接拖进面板，就能把整个文件夹连同里面的子目录原样搬过去。
- **目标有同名文件夹时默认合并**：不会报错拦住你，发起前确认一次，然后两个文件夹合并——同名的文件用你的新文件覆盖，对方多出来的文件原样保留。
- **你不用关心背后用哪种方式传**：无论直连、经过跳板机、还是用 root 帮你提权，文件夹传输都可用。唯一例外：跳板机场景下单个文件超过 10MB 传不了，会在开始前把所有超大的文件列给你看，不会传一半才失败。
- **个别文件失败不会前功尽弃**：传完后告诉你成功了几个、失败了几个，失败的文件名列出来，补传即可。
- **空文件夹也会被创建**；文件夹层级不限，但超过 40 层会提示。
- **顺带修了一个单文件下载的老 bug**：此前下载有时进度条总量不对、甚至直接报"文件不存在"，实际是程序内部参数顺序写反了，已修复。

## 新增：文件传输更顺手

- **跳板机场景单文件上限从 300KB 提到 10MB**。
- **传完之后的提示说人话**：不再显示 `sftp(root-relay)` 这类内部代号，而是「SFTP · Root 直连」「Base64 直传（Root 提权）」这样能看懂的说明。
- **批量传输遇到同名文件，可以勾「全部覆盖」**：不用一个个点确认了。勾选只对这一批生效，下一批还是会正常问你。

## 修复：改名和分组总是被"改回去"

- 这是一个让不少用户抓狂的老问题：明明把连接改了名、挪了分组，重连之后名字又变回去了；最严重的一次是改完分组名点了「全部连接」，结果只有一台机器在新分组里，其余全跑回旧分组去了。
- 原因是程序在每次连接成功后会"顺手"把连接信息存回列表，而它用的是连接那一刻的旧信息，等于拿旧数据把你的修改盖掉了。
- 现在起，**只有你亲手做的改名、移动、编辑才会改变连接的名字和位置**；重连、复制标签这些操作永远不会动你的整理结果。如果你的密码近期改过，程序也只更新密码本身，其余一律不碰。

## 修复：新建连接的智能分析

- **写明 telnet 能真正用 telnet 连了**：此前 AI 哪怕正确识别出这是 telnet 设备，创建出来的连接还是按 SSH 去连，必然失败。现在协议会被正确带上（对 telnet 自动用 23 端口）。
- **账号密码不容易被认错**：优化了识别规则。比如输入 `60.60.33.44 accon@123 passww_123`，现在会正确地把 `accon@123` 整个当作用户名、`passww_123` 当作密码——此前有时会把用户名错拆成 `accon`、密码错拆成 `123`。

## 修复：终端与文件面板

- **断线重连后终端不再串屏**（#74）：重连的一瞬间，旧会话遗留的输出偶尔会盖住新会话的内容，屏幕显示错乱。已修复。
- **切换终端标签后，文件面板跟着切**（#72）：此前面板还停留在上一个会话的目录里，点什么都没反应。
- **文件面板空白处右键有菜单了**（#73）：此前在文件列表的空白区域右键没有任何反应。

## 新增：快捷命令「发送广播」

- 命令卡右键新增「发送广播」：正在广播时发给广播组，没开广播就发给全部终端。不用先切广播模式再点命令了。

## 新增：主题与皮肤

- **新增 Windows 风格皮肤**：更接近 Windows 11 的外观（更小的圆角），在 设置 → 外观 里切换，带预览。
- **挂载在 iCode Teams 里的插件会自动跟随宿主的明暗模式**；你自己手动选过的主题不会被覆盖，随时可以恢复跟随。
- 界面配色全面规范化：修掉了 35 处对比度不足、看不清的文字，暗色模式下尤其明显。

## 实验功能：养成花园（默认关闭）

- 新增一个趣味性的"养成花园"：随着你的使用积累养成元素，呈现为可收藏的种植园场景（白天/黑夜两种景致）。**默认关闭**，感兴趣的话在 设置 → 实验功能 里开启，随时可关，数据保留。

## 已知边界

- 快捷命令导入只支持"发送字符串"类型的按钮；Xshell 的脚本、菜单类按钮会列出来但不可勾选，并注明原因。
- 导入的命令内容原样保存，`$app` 这类变量不会在导入时展开，执行效果取决于目标服务器的 shell。
- 跳板机场景的文件夹传输要求每个文件不超过 10MB；SCP 降级模式的会话暂不支持文件夹传输（会明确提示）。
- 导入的快捷命令只进入命令库，不会自动执行。
