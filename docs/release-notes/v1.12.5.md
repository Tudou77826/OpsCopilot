# OpsCopilot v1.12.5

新增数据库连接团队共享能力，全面优化数据库工作区稳定性与交互体验，并消除全部浏览器原生弹窗。

## 新功能

- **数据库连接共享（集成至「会话共享」）**：
  - 复用现有会话共享的 Git 仓库与加密密钥（`databases/<owner>.json`），数据库连接成功后自动加密同步（含数据库密码、SSH 隧道及多级堡垒机链路）。
  - 数据库左侧对象树底部新增「团队共享」面板，支持搜索过滤、折叠记忆与拖拽调高；双击自动解密、按类名匹配本机 JDBC 驱动、自动重建 SSH 隧道并收入「团队共享」分组立即连接（缺少驱动时弹窗引导打开驱动管理）。
  - 「设置 → 会话共享」同步状态新增终端与数据库条目计数展示。

## 修复与改进

- **数据库 SSH 隧道稳定性**：
  - 为数据库 SSH 隧道启用 30s Keepalive 保活，避免空闲连接被中间网络设备静默断开；完善 JDBC 断线识别（`SQLState 08xxx` / 连接关闭）并自动清理失效会话。
  - 将数据库建连与测试连接超时由 15s 放宽至 30s，改善多跳 SSH 隧道 + JDBC 冷启动体验。
- **数据库工作区交互与密度**：
  - 切换「当前数据库」下拉框时自动加载该库表列表用于 SQL 补全，无需手动展开左侧对象树。
  - 统一连接失败页签与普通查询页签交互（支持关闭按钮与右键菜单）；连接中增加顶部加载环动效，消除等待卡死感。
  - 连接树改为单行高密度布局（行高 23px，表/库/分组行距同步收紧），大幅提升多连接场景下的同屏浏览效率；精简数据库顶栏与查询页签栏。
- **主工作区视觉与字体规范**：
  - 重构主工作区页签为全高贴边样式，精简 AI 对话框底部工具栏，统一全局无衬线/等宽字体令牌并修复 Windows 输入框回退宋体的问题。
- **消除 WebView 原生弹窗**：
  - 扩展应用内 `confirmDialog.prompt()`，将删除数据库连接、重命名标签页、脚本录制命名、AI 数据库页签关闭/断开等全部原生 `confirm()` / `prompt()` 替换为应用内主题化弹窗，并新增架构守护单测禁止后续引入原生弹窗。

## 下载与升级

Windows 用户可在客户端检查更新，或下载完整的 `opscopilot-windows.zip`，解压后运行 `opscopilot.exe`。
