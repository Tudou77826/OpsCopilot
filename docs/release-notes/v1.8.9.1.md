# v1.8.9.1

## 更新内容

- 重构定位助手与 AI 对话界面，统一消息、检索轨迹、分析步骤、命令建议和知识来源的视觉结构。
- 将知识检索过程改为可折叠轨迹，修复轨迹类型与描述文字重叠的问题。
- 优化排查结论整理流程：入口移动到对话输入区附近，并使用过程性文案引导补充根因、编辑结论和最终归档。
- 统一根因输入、AI 润色、返回和继续编辑按钮的尺寸、层级与交互状态。
- 将结论编辑界面的关闭叉号改为明确的“返回”操作，避免与外层面板关闭入口混淆。
- 优化知识浏览和侧栏中的 AI 相关空状态与操作反馈。
