# v1.8.9.5

## 新增：会话连接信息共享（issue #57）

团队成员配置相同的「Git 仓库地址 + 分支 + 共享密钥」，即可互相查看最近使用的连接信息，快速完成连接。

### 共享机制

- 连接成功后自动记录该端点（主机/端口/用户/显示名/最近登录时间）并异步推送到共享 Git 仓库；推送失败自动留存，下次同步补推
- 密码、root 密码、堡垒机凭据以 AES-256-GCM 加密后存储（团队密钥经 scrypt 派生），仓库中不落明文；密钥认证的空密码连接仅共享元数据
- 共享仓库内每个用户一个文件（`sessions/<owner>.json`），跨用户零合并冲突；同一端点多条记录取「最近连接成功时间」最新者
- 共享者标识自动读取本机 `git config user.name`（缺失回退系统用户名）

### 界面

- 设置新增「会话共享」页：启用开关、仓库地址、分支、共享密钥与同步状态（条目数/待推送数/最近同步时间/手动重试）
- 会话管理面板下方新增「团队共享」区域：按最近登录排序展示，受顶部搜索框联动过滤，双击直接连接（后端解密凭据后走统一连接流程，正常打开终端页签）；右键支持「保存到我的会话」「删除共享」（仅限自己的条目）；密钥不正确时条目显示锁定图标；操作反馈使用应用内 Toast
- 共享区域支持上边缘拖拽调整高度（钳制在最小/最大值之间，为上方会话树保留最小空间）与一键折叠，高度和折叠状态本地记忆，重启后保持
- 配置入口：设置 → 会话共享；未启用时不占用面板空间

### 配置示例

```json
"session_share": {
  "enabled": true,
  "remote_url": "git@github.com:team/opscopilot-sessions.git",
  "branch": "main",
  "secret_key": "团队约定的共享密钥"
}
```

### 安全边界

- 列表接口不返回密码；连接时后端解密凭据后返回单条连接配置，交由前端走统一连接流程（与既有 Connect 架构一致）
- 本地簿记文件（`sessionstore-local.json`）只存密文，权限 0600
- 密钥不正确时给出明确提示（「共享密钥可能不正确」），不静默丢弃数据
