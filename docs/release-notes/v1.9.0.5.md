# v1.9.0.5

## 增强：升级下载链路抗网络抖动

针对网络不稳定环境下「升级总是报错」的问题，下载与版本查询链路全面加固：

- **自动重试**：下载最多 5 次尝试，指数退避（1s/2s/4s/8s）；网络抖动（连接重置、TLS 瞬断、EOF）静默自愈，不再直接报错
- **断点续传**：下载内容写入分片文件，重试时通过 Range 请求从断点继续（服务器不支持续传时自动从头重下）；多次尝试仍失败后，用户再次点击更新也会接着上次的进度继续，不必从头下载
- **防错包保护**：分片记录来源地址，版本切换后自动丢弃旧分片，不会把两个版本的数据续传到一起
- **卡死自愈加速**：连接连续无数据的判定从 60 秒收紧到 30 秒，断网挂死更快被发现并自动重连
- **智能错误分类**：4xx（除限流/分片失效）立即失败不浪费重试；磁盘类错误不重试；其余网络错误一律重试
- **版本查询加固**：检查更新、版本历史的 GitHub API 请求增加 3 次自动重试，瞬时故障不再报「检查更新失败」

## 新增：升级过程提示信息

- 下载中断时进度条下方显示「网络波动，N 秒后自动重试（第 x/5 次，已下载部分将续传）」
- 重连成功后显示「断点续传：从 X.X MB 处继续下载」，进度条从断点处继续而非回到 0
- 重试期间标题显示当前尝试次数；最终失败的错误文案汉化并给出行动建议（如「再次点击更新可从断点续传」）
