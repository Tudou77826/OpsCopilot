# v1.11.2

## 内网 HTTP 直连

客户端“设置 → 内网服务”现在可以填写 `http://IP:端口`，例如 `http://192.168.1.10:8090`。连接测试、版本查询、更新包下载、公告、反馈和获授权的运营数据上报均使用该地址。

服务端使用 HTTP 地址时，设置 `OPS_SERVICE_PUBLIC_URL=http://192.168.1.10:8090`、`OPS_SERVICE_LOCAL_HTTP=true`，并将 `OPS_SERVICE_LISTEN` 设置为客户端能访问的监听地址，例如 `0.0.0.0:8090`。`OPS_SERVICE_ADMIN_TOKEN` 仍为必填项。使用此功能需要同时更新服务端程序和桌面客户端；旧版程序只支持 HTTPS 或本机 HTTP 调试。

HTTP 不加密，包括管理凭证、反馈与更新信息在内的数据可能被网络路径上的设备读取或修改。请仅在可信、受控的网络中使用；可部署 HTTPS 时仍建议使用 HTTPS。详细配置见[部署文档](https://github.com/Tudou77826/OpsCopilot/blob/v1.11.2/docs/intranet-service-deployment.md)。
