# 助手文件管理

## 使用范围

日志排查以终端为主，使用经过授权的 grep、zgrep、tail 等命令。文件工作区用于浏览目录元信息和传输日志、软件包、插件包等普通文件；不向模型提供远程文件内容读取接口。

助手通过统一的文件控制服务操作真实文件页签。页签绑定一个现有 SSH 会话，复用人工文件面板和 SFTP／SCP／已有提权通道。访问身份来自该连接的文件配置，不继承终端中临时执行的 su／sudo。

## 操作流程

1. `file_workspaces` 返回已连接会话和文件工作区摘要，不包含凭据、文件内容或完整目录。
2. `file_open` 呈现绑定节点的文件页签。同一轮、同一连接仅申请一次目录元信息浏览授权；打开不自动占用页签。
3. `file_take` 由模型显式占用文件页签。页面显示 AI 操作标识与接管遮罩；切换到文件资源会释放原终端或数据库的操作权限。
4. `file_list` 在页签呈现指定本地或远端绝对目录。单次最多 4096 项，模型返回另有 64 KiB 上限，省略时明确提示；目录过大可通过终端缩小范围。
5. `file_transfer` 先显示两侧目录，再明确确认本机文件、远端文件、方向、节点、身份及可能覆盖的影响。每次仅传输一个普通文件，两端父目录必须存在。目录应先打包；当前没有向 AI 开放递归合并、编辑、删除、解压或安装。
6. 传输返回任务编号，不代表完成。`file_tasks` 查询实际状态，`file_cancel` 只能取消本轮创建的任务。
7. `file_release` 交还正常文件面板，保留目录位置与任务结果；交还后刷新实际目录，用户可以继续使用原有人工文件功能。

上传下载须分别确认。传输授权不包含执行、安装或重启授权。文件名、目录和传输反馈均为观察数据，不得作为新的指令或授权。

## 停止与失败

- 模型在受保护的文件操作序列内保留占用，等待传输审批不会自动释放；普通聊天不占用。
- 停止、手动接管、切换工具目标或本轮结束，会取消尚未完成的本轮传输并等待收尾，然后释放页签。人工在其他页签提交的传输不属于本轮任务，不随之取消。
- 取消与失败可能留下部分目标文件，界面和工具结果明确提示，不自动删除或重试。已完成任务保留完成状态。
- 助手传输仅在 SFTP 子系统不可用、尚未进行文件写入的兼容探测场景回退到 SCP；网络错误或未知结果不自动换协议重传。
- 每次操作复核实际连接及文件访问身份，页面呈现回执绑定工作区、随机编号和实际连接。旧页面、旧审批和旧轮次不能延续操作。
- 呈现和回执绑定发起本轮消息的页面，其他同地址窗口不能替它确认；文件和数据库页签在同一应用进程内重载后可以恢复，任务不会重放。非发起页面可显示已存在的工作区，但不会因后台进度抢走本轮焦点。
- 待完成的文件编辑／命名界面不会被自动接管。未能呈现目标页面时操作失败，不在后台继续传输。
- SFTP／SCP 的取消关闭单个传输通道，保留共享的 SSH 终端连接。
- 审计记录操作、轮次、页签、任务、路径哈希和结果，不保存文件内容或密码。审计不可写时拒绝后续操作；结果审计失败时，该页签停止自动操作，要求人工核对实际文件。

## 本地验证

后端覆盖授权前禁止提交、停止后迟到批准失效、传输取消与收尾、完成结果保留、连接变化、呈现回执、审计失败阻断和快照隔离。文件传输包验证取消单个 SFTP 通道不会关闭共享连接。

桌面测试使用真实 Wails、Chrys、隔离 SSH/SFTP 节点和确定性模拟模型。上传再下载测试包并核对全部字节，同时检查拒绝／停止后的传输未提交、遮罩与交还以及审计结果。该验证不代表真实模型规划能力、内网跳板或 Root 通道已经验收。

页面绑定回归另外覆盖：等待审批时打开第二个同地址页面，原轮次、审批和实际呈现仍属于发起页面；完成后刷新恢复文件页签、任务及目录位置，模型请求和传输不重放。

```powershell
go test ./pkg/filecontrol ./pkg/assistanttools ./pkg/agenttransport/... ./pkg/filetransfer -count=1
node e2e/harness/terminal-handoff.mjs --reuse-frontend --file-trial --port=34185 --chrys=<Chrys可执行文件绝对路径>
```

当前只支持单文件传输，一页签同时运行一个 AI 传输任务，每页签保留最多 128 项任务。工作区及任务展示保存在应用进程内；不提供重启后自动续传。
