01 / CONNECT连接与会话

  • SSH / Telnet 多协议远程终端
  • Telnet 自动登录、窗口尺寸协商与协议能力提示
  • 自然语言解析主机、账号、IP 范围等连接信息
  • SSH 跳板机穿透与自动提权
  • 跳板机连接模板，一键填入常用连接描述格式
  • 连接信息保存、分组、搜索、编辑与删除 基础能力
  • 批量连接文件夹内的多台主机
  • 连接失败后保留配置和原始描述，便于修正重试 基础能力
  • 断线保留标签并支持原会话重连 基础能力
  • 终端标签重命名、复制与连接信息复制 基础能力
  • 关闭应用前检测活动连接和未保存排查 基础能力

02 / TERMINAL终端效率

  • xterm.js 交互终端与自适应尺寸 基础能力
  • 标签自由拖拽分屏、成组、调节尺寸与折叠
  • 广播输入到多个选定终端
  • Linux 命令、参数及常用组合补全
  • Ctrl+K 自然语言生成 Linux 命令，并支持跨会话查询历史
  • Ctrl+F 搜索当前终端输出 基础能力
  • 搜索支持大小写、正则、整词、结果计数与前后跳转 基础能力
  • 规则高亮适配中文、软换行和跨行内容，危险正则隔离限时
  • 选中时间戳后转换为可读时间
  • 中键将终端选区直接发送到会话，不占系统剪贴板 基础能力
  • 快捷命令分组、搜索、编辑与执行 基础能力
  • 亮色/暗色主题、字体与字号调节 基础能力

03 / FILES文件管理

  • SFTP 文件浏览、上传与下载 基础能力
  • SFTP → SCP → Base64 三级传输降级，直传结果进行 MD5 校验
  • 拖拽上传与传输进度、取消操作 基础能力
  • 本地与远端目录浏览、面包屑导航 基础能力
  • 新建、重命名、删除和复制文件 基础能力
  • 远端文本文件直接读取与编辑 基础能力
  • 多选、范围选择、批量上传/下载及批量复制路径
  • 文件搜索、隐藏项过滤及多字段排序 基础能力
  • 下载覆盖/另存为确认及递归删除警示 基础能力
  • 覆盖前备份与自动创建远端目录
  • Root 直连或经现有 SSH 会话中继访问

04 / AIAI 辅助

  • 兼容 OpenAI 协议的模型服务 基础能力
  • 快速模型与复杂模型分别配置
  • 基于内部知识库的 AI 问答
  • Agent 自主检索、阅读并组合知识
  • 实时展示执行阶段、流式分析和可折叠检索轨迹
  • 输出可验证的诊断步骤与命令建议
  • 逐条验证命令来源，剥离无法溯源的命令；无知识命中时不猜测
  • 根因润色与排查结论辅助生成
  • 知识场景按文件和行号回溯

05 / KNOWLEDGE排查与知识闭环

  • 定位会话记录终端输入、输出和操作时间线
  • 排查过程可补充、编辑和删除事件
  • 结束时整理根因、结论和解决方案
  • 自动生成结构化 Markdown 知识记录
  • 按服务、模块、场景建立多级目录索引
  • 知识库三级树形浏览及 Markdown 正文查看 基础能力
  • 按标题、关键词、现象、组件、服务和模块全文搜索
  • 归档后立即进入后续 AI 检索范围
  • 知识补丁通过 Git 仓库同步共享
  • 同步失败补丁本地暂存、待上传计数与一键重试
  • 知识评分、问题反馈及处理状态跟踪

06 / AUTOMATE脚本复用

  • 把终端操作录制为可复用脚本
  • 脚本创建、编辑、删除和列表管理 基础能力
  • 在任意位置插入步骤，并按步骤启用或禁用命令
  • 变量占位与回放前变量输入
  • 向指定在线会话回放脚本
  • 导出为 Bash Shell 脚本

  • 单一可执行文件同时提供 GUI 与 CLI

  • file upload/download：受控文件传输
  • CLI 惰性自动连接、失效连接自愈与 Telnet warnings
  • 为 Codex、Claude Code、Cursor 等安装 Skill
  • 支持多个 Agent Skill 目录并行配置
  • Skill 安装状态检测与一键更新
  • Skill 内嵌于主程序，随单一可执行文件保持版本一致
  • GUI 与 CLI 复用同一运维和安全内核
