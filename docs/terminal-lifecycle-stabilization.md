# 终端会话与交接生命周期

状态：2026-10-20，第一批实现已完成本机隔离验证。范围为连接、重连、关闭页签、旧读写回调和固定场景接手的页面生命周期。真实 AI、通用命令授权与完整执行审计仍未接入。

## 连接身份与状态归属

页签 ID 在重连时保持不变，每条实际连接另有独立 `connectionId`。接手轮次使用自己的 `runId`，操作权继续由终端控制器的代次校验负责。三个标识分别表示页面位置、实际连接和一次运作，不相互替代。

`ConnectResult`、接手状态和断开事件携带实际连接编号。页面只呈现当前连接的接手入口、遮罩和标题标记；旧连接的断开事件不能覆盖新连接状态。空闲确认绑定实际连接，重连后必须重新确认。

## 实现边界

| 位置 | 职责 |
|---|---|
| `pkg/session/lifecycle.go` | 拨号前预约页签；连接发布、读写回调和失效清理按连接串行；不同页签使用独立锁 |
| `pkg/session/manager.go` | 注册时直接返回实际会话实例；按实例移除；先摘除注册再在锁外关闭资源 |
| `app_terminal_lifecycle.go` | 原有终端连接的发布、输出处理、断开清理及写入结果呈现；保留当前 PTY 和 Shell |
| `app.go` | 连接入口、重连状态校验、关闭协调与输出缓冲；网络拨号、读写和资源关闭不占用生命周期锁 |
| `pkg/terminalcontrol/service.go` | 接手确认核验实际连接，旧停止与旧控制器清理不能作用于替代连接 |
| `useTerminalReconnect.ts` | 去重重连；关闭、页面离开和卸载后忽略迟到结果，不重新安装监听器或弹出旧错误 |
| `useTerminalHandoff.ts` 与桌面页签适配器 | 轮次和连接快照校验，页面离开清理，重连后刷新确认与呈现 |

关闭页签会撤销连接轮次、接手操作权并清理注册、配置引用、命令提取器和旧输出缓冲。已有传输连接但仍在启动 Shell 时，关闭会主动关闭该传输；尚未返回的拨号结果随后到达时会被拒绝并释放，不能复活页签。实际拨号本身沿用现有协议超时，未新增可取消拨号协议。

正常 EOF 保留断开状态以供重连，先失效控制与登记断开，再发送通知。已摘除的连接和缓存传输在锁外关闭，慢关闭不阻塞其他页签或移除新实例。

终端读写本身仍走原专用通道。聚合读取可能跨越关闭或重连，因此聚合完成后再校验连接轮次。旧输出、旧读写错误、命令提取及断开清理均不能修改新连接现场。已经提交给旧传输的字节无法撤回。

## 验证

只使用内存端点和本机临时 SSH/PTY，未连接业务服务器。

- 相关 Go 包及桌面终端回归重复五轮，相关静态检查通过。覆盖重复重连、拨号/启动 Shell 期间关闭、旧普通读取/聚合读取/写入错误迟到、EOF、缓冲失效、资源关闭与连接确认。
- 前端 30 项相关测试、TypeScript 检查和构建通过。覆盖重连去重、旧响应失效、连接快照隔离、确认重置、遮罩及既有终端/拖拽行为。
- ash、Bash 真实 SSH PTY 各三轮通过，验证同 Shell、目录/环境延续、账号切换、未知状态拒绝和中断后的真实提示符。
- 完整页面八项通过：同 Shell 延续、竞争输入拒绝、其他页签可用、手动接管、中止按钮、重连后重新确认、刷新释放占用、关闭页签释放占用；页面脚本错误为零。

PTY 中断测试的就绪信号由已安装中断处理的前台程序发出，避免父 Shell 提前打印后与后续进程启动竞争。该用例验证确定就绪的前台程序可中断，不将任意时点发送 Ctrl+C 等同于远端进程必然结束。

最终本机页面证据保存在忽略目录 `e2e/.runtime/handoff-desktop-1792469170550/result.json`；PTY 与页面日志分别为 `e2e/.runtime/terminal-lifecycle-pty.log`、`e2e/.runtime/terminal-lifecycle-e2e.log`。页面退出时仍有 Wails 开发模式的 WebSocket 关闭日志；页面脚本错误为零不表示后端日志为空。
