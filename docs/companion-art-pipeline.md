# 伙伴资源生产规范

伙伴、奖章与背景采用独立资源契约。功能边界见 [伙伴系统设计](companion-system-design.md)。

## 正式资源

| 资源 | 尺寸与存储 | 显示方式 |
| --- | --- | --- |
| 七种伙伴 | 微光 `lumen-v8`，其余 `<species>-v7`；256×256 全色透明 PNG | 正常缩放，保留软边缘、纹理和颜色层次 |
| 八类四等级奖章 | `medals/v2`，128×128 全色透明 PNG | 助手中右侧纵排、48px；列表使用紧凑缩略图 |
| 场景与资料背景 | `scenes/v2`，1536×1024 WebP，浅深两张 | 随应用主题切换，保留简洁地面与边缘细节 |

不得对角色或奖章追加低分辨率像素化、颜色量化或透明边缘二值化。所有游戏等级共用角色母版与固定体型。为保持已验收的显示尺寸，运行时固定使用美术包历史child索引及其160/216基础比例，再乘以显示比例0.7；历史growing/adult索引保留在资源契约内，不再对应游戏阶段。绘制、步幅和活动范围共用固定比例，容器尺寸保持稳定。换色保留像素明暗、饱和度与 Alpha，中性色保持。业务名称、等级、经验和数量由界面绘制。

侧边栏入口和收起后的身份头像使用独立静态展示，分别为40px和36px。头像裁掉母版画布的透明留白，不应用成长或场景缩放，不增加动画定时器；大场景继续使用上述0.7比例。

## 每个动作独立生产

[roster-v5](../art/companion/roster-v5/README.md) 保存七种角色招呼、舒展、开心、行走共28组新原稿、提示词与修正规格；待机、环顾、休息沿用roster-v4的21组原稿。每次生成只包含一种动作，使用已认可的站姿作为身份参考。角色服装、装饰、身体比例与肢体所属关系必须跨动作一致。

| 动作 | 原生帧数 | 播放节奏 |
| --- | ---: | --- |
| 待机眨眼 | 8 | 4.2秒周期，长站立、短眨眼 |
| 招呼、开心、舒展 | 各12 | 12fps，中间姿态按需停留 |
| 环顾 | 12 | 转向160ms/姿态，两侧各停留1300ms |
| 休息 | 8 | 低频长停留 |
| 行走原稿 | 32 | 转出4 → 起步4 → 步行16 → 停步4 → 转入4 |
| 步行循环 | 16 | 12fps，完整周期1.333秒 |
| 侧身站立 | 1，共用停步末帧 | 用于暂停与安全冻结；完整行走随后回正待机 |

原稿要求完整轮廓和透明格间留白，行走循环始终朝右；左向由显示镜像得到。对侧脚接触表示换脚，不能换朝向。招呼全程使用同一只前爪或翼。可见角色装饰不作为噪点清除。

各角色按身体结构分别生成：四足动物不添加人类手臂，抬爪必须移走原位置的爪；鸟翼展开后不能保留原折翼；衣物不作为额外肢体。候选图与正式帧分别审查，不能以提示词包含肢体数量作为合格证据。

```powershell
node tools/pixel/build-roster-actions.mjs
```

处理程序寻找透明间隔分格，检查主体不贴原稿裁切边界，保留半透明边缘及角色附近装饰。站立类动作按脚底和下半身配准；跳跃保留离地高度。共用缩放与安全边距限制配准偏移，防止平移切掉耳朵、尾巴或肢体。缩放采用预乘 Alpha 双线性采样，无损 PNG 编码保留正式 RGBA。全部七包验证完成后才复制到正式目录。

## 动作契约与播放

角色契约 `contractVersion: 2` 声明资源、阶段比例、基础与环境动作、锚点 `(128,240)`、逐帧时长和循环标记。`locomotion` 追加步幅、脚接触帧、对侧接触收步片段和转出、起步、停步、转入、侧站片段；`staticFrame` 指定减少动态效果时的代表姿态。内容包不声明经验、奖章门槛或业务执行行为。

助手以少量片段组成动作序列。图片准备完成后，共用开始时间启动姿态播放和浏览器 `transform` 位移。行走距离是显示步幅的整数倍，周期完整结束在接触姿态，再播放停步、转回正面并进入待机；改变方向先转回正面再转出。行走中点击在下一脚接触时停止，使用当前接触对应的收步片段进入停步、转入与回应，保留位置。

每周期原生步幅48–60px，随角色显示比例缩放，当前420px场景中七角色均可完成至少一周期。空间不足以容纳完整步幅时不强行越界。日常以呼吸和眨眼为主，环境动作间隔45–75秒；六次环境动作只有一次舒展、一次走动。

非行走动作共用站姿端点；转出、起步、循环、停步、侧站和转入的公共端点必须为相同解码像素。公共端点只是必要条件，仍须检查相邻帧身体比例、服装、朝向和动作速度是否连续。

静态缩略图只读取代表帧，活动动作按片段加载；当前片段准备期间保留上一姿态。换色缓存上限128项，播放循环不操作 Canvas，仅在下一姿态边界唤醒。单帧侧站没有重复姿态定时器。隐藏、离屏、收起和减少动态效果停止调度及位移；尺寸变化冻结并限制位置，保留朝向。角色之间不提前下载整套动画。

## 门禁与验收

```powershell
node tools/checks/check-companion-assets.mjs
node --test tools/checks/check-companion-assets.test.mjs tools/checks/check-locomotion-assets.test.mjs tools/checks/check-ambient-assets.test.mjs tools/checks/check-medal-assets.test.mjs tools/pixel/*.test.mjs
```

门禁检查真实尺寸、透明度、安全路径、完整动作、时长、脚接触、代表帧、公共端点和体积。角色高可见轮廓保留8px输出边距；单帧不超过180KB、单包不超过8MB。正式七包共664张帧资源、35,541,557字节；一些公共端点内容相同，构建器会复用相同输出。奖章共763,043字节。历史原稿和包保留，运行登记引用微光v8和其他六包v7。

微光v8使用兔形坐卧、低伏跳步和贴地舒展，不使用直立、举手素材。原稿在 `art/companion/reviews/rabbit-v1`，新增动作提示词见 `runtime-sources.json`，通过 `node tools/pixel/build-rabbit.mjs` 输出正式包。构建在运行目录外创建候选包，完成全部格式与公共端点验证后才写入正式资源；无效候选不得覆盖现有包。招呼和开心共用8帧耳部回应，待机与休息各8帧，观察、舒展各12帧，跳步16帧；转出、转入各8帧，起步与停步各4帧。观察跳过原稿中重复转向，两侧各停留1.3秒。跳步只有帧0作为安全接触，点击等待完整落地后停止；不沿用其他角色的双接触设定。

实际播放验收覆盖七种身份一致性、眨眼根部稳定、动作邻帧、起步与停步、左右行走、点击打断、换色、大小窗口、隐藏和减少动态效果。格式门禁和截图不能代替完整动作播放审查。行为与性能记录见 [性能验收](companion-performance.md)，当前身体结构和节奏检查见 [v7复核](companion-anatomy-review.md)；v6独立报告作为历史保留。
