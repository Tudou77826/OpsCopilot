# 助手本地项目与目录

## 使用方式

输入框工具栏显示当前本地项目。项目保存独立目录组，例如 A 项目有三个目录，B 项目有一个目录；切换项目后只将所选项目的目录注入后续消息。已有聊天保留。

项目入口支持创建、切换、重命名和移除。目录可以粘贴绝对路径或通过系统选择器添加，重复路径不重复保存。最多保存 64 个项目，每个项目最多 16 个目录。移除项目仅删除配置，不删除磁盘文件。

配置和当前项目保存于应用配置目录的 `assistant-projects.json`，刷新、重启或新建对话后仍保留。写入使用跨进程锁和原子替换；配置损坏时返回错误，不覆盖原文件。保存路径暂时不存在时仍保留配置，使用时需检查实际可用性。

Agent 使用 `local_directories` 查询项目及 `activeId`，使用 `local_add_directories` 显式提交 `project_id`、多个绝对路径和用途。宿主按[任务范围及操作后果](assistant-authorization.md)判断，用户要求的低风险配置可自动保存；需要确认时展示目标项目及完整路径。不自动切换当前选择。拒绝、停止或过期的确认不追加；目标项目被删除时失败，不能转加到其他项目。人工修改配置需等待本轮完成或先停止。

## 执行边界

目录列表表示本机资源位置，不是文件系统沙箱或读写权限白名单。移除目录表示不再将它提供为工作位置，不等于撤销操作系统访问权限。

每条消息附带当前项目及其目录，其他项目的目录不自动混入消息上下文。Agent 当轮追加的目录通过工具结果可用。切换项目不清除聊天，旧项目的工具结果是历史记录，不能继续当作新项目的现场。本机文件查看、写入和脚本执行仍使用 Chrys 原生工具及绝对路径，不更换会话内部的临时工作目录或 Chrys 原生工作区配置。敏感读取、文件修改和命令执行保持现有审批与审计规则。新增目录不会自动读取内容、加载其中的 Skill 或扩大远程资源授权。

多个目录可能匹配任务时，Agent 应先确认使用哪个目录。选中 SSH 终端时，“当前机器”仍默认指向该远程节点，不能因存在本地目录而把远程任务转为本机操作。

## 验证

后端测试覆盖项目隔离、重新加载持久化文件、并发编辑、损坏配置保护、目录校验与去重、确认前不生效、拒绝和停止，以及等待确认期间切换或删除项目的处理。界面测试覆盖创建、切换、重命名、移除确认、目录管理、运行时禁止修改和错误提示。

桌面链路使用真实 Wails 与 Chrys、确定性模型和隔离目录，验证 A 项目三个目录、B 项目一个目录，Agent 向明确项目追加并使用原生文件工具读取测试内容，以及切换项目更新消息上下文、刷新和新建对话保留持久化配置。该验证不代表操作系统沙箱或任意脚本的路径隔离。

```powershell
go test ./pkg/assistantlocal ./pkg/assistanttools ./pkg/agenttransport/... -count=1
node e2e/harness/terminal-handoff.mjs --reuse-frontend --local-directories-trial --port=34185 --chrys=<Chrys可执行文件绝对路径>
```
