# 助手 Skills 与快捷命令

Skill 提供业务知识、部署线索和操作方法；Command 提供常用指令及确定的填写项。业务发现逻辑由 Skill 和 Chrys 执行，工作台操作继续经过应用的统一接口。

## 使用入口

在 AI 输入框工具栏打开资源库：

- **Skills**：从包含 `SKILL.md` 的目录导入，查看正文及文件列表、更新、启停和移除。
- **快捷命令**：登记名称、用途、可选关联 Skill，以及提示词模板。名称支持大小写字母、数字、下划线和连字符，以字母开头，最长 64 字符。

输入框键入 `/` 后搜索命令，方向键选择、Enter 确认、Escape 关闭菜单。选择后提示词进入输入框，高亮空位可填写文字或选择已保存的 SSH 连接，Tab 在空位间移动，正文也可以编辑。必填项完成后才能发送；运行中发送沿用消息队列，不启动并行 AI。

模板使用 `{{management}}` 一类标记。编辑器自动识别空位，可设置显示名称、文字/SSH 连接类型及是否必填。连接项提交真实保存连接 ID，发送前重新检查其是否存在。密码通过应用连接表单填写，不提供密码型模板项。

例如用户可以登记 `/sqlSessionInfoGetAndCreate`，关联自己导入的业务发现 Skill：

```text
请在 {{management}} 上获取 {{business}} 的数据库连接信息，保存连接并打开 SQL 页签。
```

命令不内置业务算法。AI 加载 Skill，取得实际信息，再通过数据库工具创建配置、打开完整页签，追加带用途注释的原始 SQL。交还后用户继续使用该页签。

## 助手读取知识与快捷命令

助手通过应用 MCP 工具按需读取现有定位经验和用户命令，无需额外导入 Skill，也不要求 SSH 连接或占用页签。

| 工具 | 内容 |
|---|---|
| `knowledge_list` | 分页浏览场景，可按服务、模块筛选 |
| `knowledge_search` | 按症状、关键词、错误码搜索已有经验 |
| `knowledge_read` | 按返回的场景 ID 读取正文、标题和来源 |
| `quick_command_list` | 浏览、搜索终端快捷命令与 AI `/` 命令的元信息 |
| `quick_command_read` | 按类型和 ID 读取命令定义、模板空位及关联 Skill |

知识来源与知识浏览器一致，复用现有解析和搜索实现；读取不生成或修改归档文件，也不写知识索引。列表默认每页 25 条，搜索默认 5 条，最多 50 条；可用 `offset` 继续浏览列表。正文最多返回 32 KiB，并标识截断及常见凭据形式的脱敏。知识为空时返回空结果，实际读取失败则报错。

快捷命令的 `kind` 区分 `terminal`（终端 Shell 片段）与 `assistant`（AI 提示词模板）；后者的 ID 为命令名称。列表不返回命令正文，读取定义不会执行或发送命令。关联 Skill 已停用的模板标记为不可用；缺少必填参数时由助手询问用户。命令定义与经验均为参考资料，不构成本次操作授权。后续执行继续使用正常终端、数据库或文件工具及其审批规则，禁止猜测被隐藏或截断的命令内容。

应用工具调用通过统一入口留下紧凑记录，覆盖知识、快捷命令、目录、终端页签、数据库元数据和文件浏览。已有 SQL、命令执行及传输记录继续保留，不重复添加同一次调用；轮询传输状态更新同一行。同轮连续操作默认折叠，展开查看结果摘要、读取的正文片段和调用用时；失败保持可见。接管与交还等软件过程收在过程记录中。

整轮耗时分为助手响应、工具执行和等待确认，按宿主观察到的墙钟时间统计。助手响应包含启动、网络、生成和桥接等等待，不等于模型服务端推理时长；人工确认等待从工具执行中排除。单条调用用时包含该调用内部的确认等待。耗时仅作界面诊断，不改变审批、锁定或取消规则，也不作为恢复对话的业务事实。

## Skill 包与更新

`SKILL.md` 使用 YAML 头部声明 `name`、`description`，正文使用 Markdown。名称为小写字母、数字和单连字符，最长 64 字符；描述不能为空且不超过 1024 字节。导入以名称建立本机副本，源目录不变。

保留包内普通文件，包括参考资料、脚本和资源。仅加载应用管理的 `assistant-skills`，不扫描其他 Agent 目录。最多 32 个 Skill，每包 512 个目录/文件条目，单文件 8 MiB、单包 32 MiB、全库 64 MiB；`SKILL.md` 为 64 KiB 内 UTF-8 文本。不接受符号链接。

同名包通过更新入口替换并核对名称。关联命令使用的 Skill 需先解除关联才能移除；停用时对应命令从 `/` 菜单隐藏。运行中可浏览，配置变更需等待本轮结束。

每轮开始生成启用包的内容快照；版本未变则复用，版本改变时更新 Chrys 原生 Skill 路径并重载当前会话，不清空对话。旧快照保留至对话结束，避免历史路径被替换。停用包不再出现在下一轮可用目录，但历史对话已经观察到的知识不会被擦除。

## 执行、授权和审计

Chrys 的本地 Shell、文件和搜索工具已接通，不需要 SSH。`load_skill`、`read_skill_resource` 按需加载正文和资源；`run_skill_script` 使用原生解释器选择、超时与取消。Python、Bash、Java 等依赖是否可用，取决于本机及脚本实际需要；不另建脚本管理或插件运行器。

操作软件中的远程终端、数据库和页签必须使用应用 MCP 工具，保留目标核验、用户同意、显式占用和交还。Skill 不授予权限，也不是当前服务器状态的证据。它不是隔离沙箱，附带脚本应来自可信来源。

本地工具保留 Chrys 的只读辅助判定与敏感路径检查。需要确认的操作经 ACP 单次授权呈现，界面标示「本机」。停止撤销当前等待和旧批准。宿主记录工具事件、授权决定、轮次及调用摘要，不把原始参数、输出或凭据写入审计；原操作在授权界面展示。审计失败时不批准新操作，并停止本轮。

审计位于配置目录 `audit/assistant/native.jsonl`，上限 16 MiB，达到上限会报错停止，自动归档暂未实现。终端和数据库继续使用各自的执行审计。授权或调用开始不等于操作成功。

## 代码边界与验证

- `pkg/assistantskills/library.go`：完整包导入、启停、快照和 Command 持久化，不执行脚本。
- `pkg/agenttransport/acp/`：原生能力配置、逐轮权限绑定、Skill 热更新与脱敏审计。
- `app_assistant_library.go`：桌面入口、填写项和保存连接 ID 校验，不直接运行命令或连接数据库。
- `frontend/src/components/AssistantLibrary/`：管理面板、`/` 菜单及句内填空。

原文本加载器保留给文本契约测试，正式助手使用完整原生包快照。测试示例仅位于 `e2e/fixtures/` 或临时目录，不随发行版预置。原生联调使用未修改的本机 Chrys 和确定性模型，覆盖 Python 执行、一次批准、资源路径保护及更新后同一会话继续，不证明模型已掌握某个内网业务流程。

本地完整验收入口为 `e2e/harness/terminal-handoff.mjs --database-trial --command-trial`，需提供隔离数据库、导入 JAR 和 JDBC 运行目录，验证登记命令、填写空位、Skill 执行、数据库页签及人工接续。内网发现逻辑、Gauss 和跳板链仍需对应环境复测。
