# 内网服务中心部署与验收

## 交付范围

独立服务程序位于 `cmd/service-center`，提供产品与帮助网页、正式版本镜像、历史下载、公告、反馈及运营统计。管理员通过 `/admin` 管理公告、回复反馈、查看统计、存储用量和同步状态。业务记录保存到 bbolt 数据库，安装包和用户主动选择的附件保存到文件目录。

桌面客户端在“设置 → 内网服务”配置 HTTPS 根地址。底栏提供产品介绍、反馈和有效公告；首次启动展示离线采集说明，用户先选择同意上报或拒绝上报，拒绝后可另行同意最简方案或完全关闭。共享知识库及共享连接信息保留各自配置和权限。

## 运行配置

| 环境变量 | 说明 |
|---|---|
| `OPS_SERVICE_PUBLIC_URL` | 必填，客户端访问的 HTTPS 根地址，例如 `https://ops.example.internal`，不带路径或查询参数 |
| `OPS_SERVICE_ADMIN_TOKEN` | 必填，至少 32 字符的随机管理员令牌，通过受限环境文件或部署系统注入 |
| `OPS_SERVICE_DATA` | 数据目录，默认 `./service-data`；容器中为 `/data` |
| `OPS_SERVICE_LISTEN` | 监听地址，默认 `127.0.0.1:9080` |
| `OPS_SERVICE_GITHUB_TOKEN` | 可选，服务端访问 GitHub API 的令牌；不发送给客户端 |
| `OPS_SERVICE_LOCAL_HTTP` | 仅本地网页调试设为 `true`，允许 `http://127.0.0.1`、`http://localhost` 或 `http://[::1]` 的服务地址；默认关闭，不用于客户端升级接入 |

服务器需要能访问 GitHub API、GitHub 发布附件及附件重定向的下载域名。客户端只需要访问内网服务地址，并信任其 HTTPS 证书。

### 容器部署

在 `deploy/service-center` 下创建不入库的 `.env` 文件，写入公网根地址变量和随机管理员令牌。该地址应为内网域名；变量名中的 `PUBLIC` 表示客户端可见地址。限制 `.env` 读取权限。

```sh
docker compose up -d --build
```

使用同目录 `nginx.conf.example` 配置内网 HTTPS 反向代理，替换域名和证书路径。服务仅映射到主机回环地址，不直接暴露管理接口的明文端口。反向代理、负载均衡、WAF 和外围监控均应关闭记录客户端 IP、查询参数、请求正文及身份标识的访问日志；示例已关闭 nginx 访问及可能包含客户端信息的错误日志。

服务每小时同步一次最新正式版本，管理员可手工触发。全部附件下载完成、大小匹配并计算 SHA-256 后才发布；GitHub 提供摘要时同时校验上游摘要。未提供上游摘要的附件以 HTTPS 来源、声明大小及本地 SHA-256 为完整性依据。历史版本从已同步版本逐步积累，不回溯导入全部 GitHub 历史安装包。

### 直接运行

从 GitHub Release 下载与服务器 CPU 架构匹配的 `opscopilot-service-center-linux-amd64` 或 `opscopilot-service-center-linux-arm64`，赋予执行权限后运行。程序已包含门户和管理页面，无需安装 Go、glibc 或数据库服务。服务器仍需提供可写数据目录、系统 CA 证书、GitHub 出口及内网 HTTPS 反向代理。不同 CPU 架构不能共用同一个程序；amd64 构建使用通用 x86-64 指令集，arm64 构建面向 ARMv8.0。

若需从源码构建：

```sh
CGO_ENABLED=0 go build -trimpath -o service-center ./cmd/service-center
```

通过进程管理器设置上述环境变量后运行程序，并配置 HTTPS 反向代理。数据目录只允许服务账号读写；同一数据目录只运行一个服务实例。Windows 可构建为 `service-center.exe`。

## 客户端接入

1. 老客户端手工安装一次包含此功能的版本。
2. 在“设置 → 内网服务”保存内网 HTTPS 地址。
3. 用户选择上报模式。地址变更后，已同意的用户需重新确认；已拒绝的用户保持关闭。
4. 已配置地址时，版本查询、更新日志和安装包下载走内网，失败不会退回 GitHub。未配置地址保留原有 GitHub 更新能力。

服务地址和授权状态独立保存在安装配置目录的 `service-center.json`，自更新不会覆盖此文件。拒绝或未授权时不生成统计安装标识、使用记录或待发队列，且不请求采集说明或统计接口。每次计数、入队和发送检查授权；同意后先确认说明版本，无法确认时停止采集。队列最多保留 7 天、1,000 条，撤回时清空并取消待发请求。

常规与最简上报的字段定义位于 `pkg/servicecenter/protocol.go`，客户端弹窗使用同一份内置说明。扩大范围、改变用途、接收方或保存期限必须修改说明并提高对应授权范围版本（常规 `PolicyVersion=3`，最简 `MinimalPolicyVersion=2`），发布客户端后重新征求同意。单纯文案修订保持说明版本。关闭上报不会删除已送达记录，服务端按期限清理。

## 管理与备份

- `/admin` 使用管理员令牌登录，令牌仅保存在当前页面内存；刷新后重新登录。
- 公告使用纯文本、排序值、开始和结束时间，详情链接限同一服务域名。
- 反馈仅发送用户填写内容和主动选择的附件，附件上限 5 MB；查询需编号和独立凭证。附件仅管理员可下载。
- 统计按累计计数幂等更新。仪表盘只代表同意采集的安装实例，安装量不能当作人数。
- 每小时清理超过 90 天的实例记录，并在同一数据库事务中转为不含安装标识的日汇总；日汇总保留一年。服务不记录 HTTP 访问日志或请求正文，不保存诊断和崩溃日志。
- 备份前停止服务，备份整个数据目录，包括 `service.db`、`downloads` 和 `feedback`。恢复时使用同一客户端可见地址与管理员配置。

## 验收流程

| 场景 | 预期 |
|---|---|
| 客户端断外网、内网服务在线 | 能查询版本、查看更新说明并下载内网安装包 |
| 服务端外网中断 | 上次完整镜像及历史下载继续可用 |
| 截断或修改安装包 | 不发布未完整版本；客户端校验失败不解压安装 |
| 首次未选择、拒绝、关闭弹窗 | 无统计采集、缓存和统计请求 |
| 同意后执行连接、Ctrl+K 和快捷命令 | 仅增加对应每日计数，不发送操作内容 |
| 自动重连、按键长按、重发同一批记录 | 不重复增加计数 |
| 上报中撤回授权、重启客户端 | 取消待发请求、清空队列并保持关闭 |
| 用户拒绝后使用共享功能 | 仍按原权限使用共享知识库和共享连接信息 |
| 公告过期、获取失败 | 隐藏过期公告，失败时仅使用仍有效的缓存 |
| 主动反馈提交与查询 | 返回编号及凭证，管理员回复后可查询进度 |
| 升级仅下载、尚未启动目标版本 | 不计升级完成；目标版本启动后才记录启动成功 |

自动化验证命令：

```sh
go test ./...
cd frontend
npm test -- --run src/components/ServiceCenter/ServiceCenter.test.tsx src/components/BottomBar/BottomBar.test.tsx src/components/SettingsModal/AboutPanel.test.tsx
npm run build
```

自动化测试覆盖授权、撤回及取消请求、跨窗口拒绝、计数与幂等、字段白名单、镜像发布与 Range、外网故障、反馈凭证、公告有效期、安装包校验及数据保留。实际内网证书、GitHub 出口、反向代理和桌面进程替换需在部署环境按表验收。

### 管理控制台与演示模式

`/admin` 提供服务总览、版本镜像、公告管理、用户反馈和运营数据五个工作区。真实管理数据需要管理员令牌；令牌仅保存在当前页面内存中，退出或刷新后清除。

登录页的“打开演示控制台”进入 `/admin?demo=1`。演示包含模拟版本、公告、反馈和日统计，支持公告编辑、反馈筛选与回复；所有变更只保存在页面内存，刷新或“重置示例”恢复。演示不读取或写入管理接口，也不执行真实版本同步，不创建模拟用户上报记录。

控制台资源位于 `internal/servicecenter/admin/`，由 Go embed 随服务发布；修改后重新构建服务即可。

### 产品门户维护

服务首页复用 `docs/opscopilot-product-homepage.html`，功能清单复用 `docs/opscopilot-feature-checklist.html`。个人网站的项目详情页仍由个人网站独立维护。

修改原稿后，在仓库根目录执行 `python deploy/service-center/bundle-portal.py`，再重新构建服务。打包脚本将样式和脚本拆分为本地资源，复制引用的截图与标识，生成 `internal/servicecenter/portal/`；这些资源通过 Go embed 随服务发布，无需运行时读取 docs 目录或访问外网字体、图片服务。

门户下载按钮跳转到内网下载区，由 `/api/v1/releases` 展示完整同步的安装包与更新说明。帮助与反馈指向本站对应页面；开源项目与 Star 保留为可选外网链接。

## 扩展使用统计

常规授权收集桌面脚本、定位、归档、知识查询、传输、命令生成及 CLI 各入口的每日固定计数。详细定义见设计文档。最简范围保持不变；旧常规授权需重新确认。

后台“运营数据”可按日期查看桌面与 CLI 的发起、完成、失败、取消，以及策略拒绝与连接恢复。`/admin?demo=1` 提供模拟计数，不写真实数据库。日汇总 `usage` 仅接受协议白名单，累计快照重复发送按各计数最大值更新。
