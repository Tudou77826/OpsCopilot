# 服务端 CLI 代码审查记录

日期：2026-10-26。范围：独立 CLI、Session 存储、单次 SSH 执行、SQL／下载适配、相关测试和构建配置。

## 结论

保留独立宿主复用领域能力的分层。审查发现执行语义、取消传播、脱敏和测试有效性存在实际缺口，已修正并增加回归用例。此前“测试通过”不能替代这些行为的验收。

## 发现与修正

| 优先级 | 问题与影响 | 修正及验证 |
|---|---|---|
| P1 | 目录失败后，分号或 `\|\|` 后的命令仍可能在原目录运行 | 将完整命令分组；真实 Linux Shell 用例先复现后通过 |
| P1 | SSH 已收到执行请求、确认回包丢失时返回普通失败，不能反映结果未知 | 增加 `startAttempted`；未确认完成时返回 `unknown`，测试断开确认链路并核对没有重跑 |
| P1 | Session 等待元数据锁不响应取消，关闭可能超过截止时间，watcher 拖延退出 | 元数据操作与 watcher 使用可取消的跨进程锁。原 40 ms 截止的关闭等了约 438 ms 后仍返回成功，修复后在限定窗口内返回截止错误 |
| P1 | 短密码为长密码前缀时，按顺序替换会残留长密码后缀 | 最长匹配、一次替换；覆盖重叠凭据回归，复用到错误和数据库结果 |
| P2 | 取消测试的命令被白名单拒绝，实际未进入 SSH；截断仅检查字段存在，失败未核对退出码 | 等待服务端收到允许的长命令，再由关闭触发取消；核对 `cancelled`、真实字节数、`truncated=true`、退出码 7 和 stderr |
| P2 | 状态文件和密钥先整体读入再检查大小 | 读前检查类型与大小，读取阶段再限额，拒绝目录、超大文件和增长后越界 |
| P2 | iCode 初始化错误覆盖原 RPC／截止异常 | 保留内部错误链，保持对外消息简洁；测试验证可追溯且不直接回显原始错误 |

另调整：显式配置的 JDBC／iCode 测试环境缺失时失败，不能伪装为未启用的跳过；CI 补充依赖文件与远程接口、文件传输路径触发条件。

## CLI 易用性检查

调用入口补齐分级帮助、必填参数和 JSON 示例；帮助可在未配置环境时运行。未知命令和缺失参数在加载 Session／连接前报告，错误 JSON 提供可选 `hint`，指向对应帮助或 Session 恢复／关闭方式。

`database query` 支持本机 UTF-8 SQL 文件和 stdin，明确大小上限、互斥参数及错误；输入沿用相同查询和只读事务路径。`driver list` 保留既有字段，新增按驱动区分的服务端只读适配说明，避免将驱动已导入理解为数据库已兼容。

验证包含 Windows 相关包回归与静态检查、Linux 下完整 CLI 包测试和独立进程 SSH／SFTP。SQL 文件、stdin 的实际查询结果及写入拒绝通过隔离 MySQL 8.4.8、Java 21 和 JDBC 验证。调用文档与两份 Skill 已同步。

## 复测与限制

全仓库 Go 回归、相关包静态检查、Linux Session／CLI SSH／SFTP／真实 Shell、实际 Java／MySQL，以及实际 iCode 调用 CLI 均纳入复测。iCode 使用确定性模型替身，只验证调用链与工具 Session 复用。

iCode 联测曾出现一次会话初始化失败；原错误链被覆盖，无法确认首次失败根因。补齐诊断后重跑通过，耗时约 33 秒。重跑通过不代表已根治初始化不稳定，保留为运行环境联合验收的观察项。

数据库通用方言只读适配、目标内网及 arm64 实机仍属于 [验证范围与限制](server-cli-validation.md) 中的待验收内容。
