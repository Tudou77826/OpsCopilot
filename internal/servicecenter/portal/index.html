01 / CONNECT
痛点：一个跳板机后面挂着多个业务节点

登录、切用户、SSH、再切用户。每台机器都重复一遍。

复杂现场真正麻烦的不是输入 IP，而是每个节点都要走同一套机械流程。节点一多，连接准备既耗时，也容易连错环境或漏掉步骤。

OpsCopilot 怎么解决

把跳板机、业务节点和自动提权写成一份连接模板。OpsCopilot 自动解析配置，通过同一跳板机批量进入多个节点，并保留为可搜索、可重连的会话。

配置一次跳板机、节点范围、账号
自动完成登录、SSH、切换用户
直接开始分屏、广播、多节点处置
把重复登录流程压缩成一次连接动作。
02 / ARCHIVE
痛点：问题解决了，真正有价值的判断过程没有留下

工单写了“已恢复”，下一位同事仍然不知道当时怎么查的。

命令、输出和临场判断散落在终端与聊天记录中。事后补文档成本很高，通常只剩一句结论，无法成为下一次排障的可靠依据。

OpsCopilot 怎么解决

记录排查时间线，补充根因后由 AI 整理关键词、问题现象、涉及组件、排查路径和解决方案，生成结构化 Markdown，并按服务、模块和场景归档。

现场记录命令、输出、关键事件
AI 整理现象、根因、路径、结论
团队沉淀归档并通过 Git 分享

知识库浏览是辅助入口：需要时可以人工查看，但更主要的价值是让 AI 在后续排障中直接消费这些记录。

不额外写复盘，也能留下可复用经验。
03 / DIAGNOSE
痛点：团队已经处理过，下一次却还是从头查

归档不是终点。相似故障再次发生时，经验应该主动回来。

通用 AI 不知道企业内部系统，更不知道上一次故障的真实现象、验证命令和最终结论。仅仅把文档放进目录，并不会自动缩短定位路径。

OpsCopilot 怎么消费归档经验

描述当前现象后，Agent 自动搜索、阅读并组合历史定位记录，展示检索轨迹，输出综合分析、定位步骤和建议命令；每条命令都能回溯到原始文件与行号，无知识时不猜测。

通用回答

给出可能正确，但不了解企业现场的建议。

团队经验驱动

引用真实归档，告诉你为什么这样查、依据在哪里。

上一位工程师的经验，成为下一次定位的起点。
04 / REUSE
痛点：业务操作有固定步骤，却一直靠记忆和复制粘贴

把固定业务操作录成脚本，换台服务器也能直接复用。

这类操作并不复杂，但步骤顺序、参数和目标节点不能错。只存在个人笔记里，换个人执行就要重新理解一遍。

OpsCopilot 怎么解决

把真实终端操作录制成有业务名称的脚本，补充用途说明，设置变量、启停步骤，再向选定会话回放；也可以导出为 Bash 脚本。

录制按正常方式完成一次操作
整理业务命名、变量化、备注
复用换节点后直接回放
让同一套业务操作稳定地重复执行。
05 / FILES
一体化工作流：文件操作延续当前会话上下文

上传补丁、下载日志、查看配置，都在当前会话里完成。

从终端发现问题后，直接使用同一条 SSH 连接处理相关文件，无需重新打开客户端、选择服务器和定位目录，排查上下文始终保持连续。

OpsCopilot 提供什么

同屏浏览本地与远端目录，完成拖拽、批量传输、进度控制和文本编辑；遇到受限环境时，自动在 SFTP、SCP 与 Base64 之间选择可用方式。

沿用会话直接复用当前 SSH 连接
同屏操作本地与远端目录并列处理
过程可控校验、备份、进度与覆盖确认
终端操作与文件处理保持在同一现场。
06 / COMMAND QUERY
痛点：低频复杂命令，用到时总要重新查写法

直接说出目的，马上得到可执行的 Linux 命令。

查大文件、看端口占用、筛日志或组合 find、awk、sed 时，常常要现查参数。问题不难，但会打断当前排查节奏。

OpsCopilot 怎么解决

在任意终端按下 Ctrl + K，用自然语言描述目的。快速模型返回 Linux 命令与解释，可以复制、重新生成，或直接键入当前终端后由你确认执行。

呼出无需离开当前终端
生成命令和用途一起返回
复用历史可搜、可置顶
少查一次手册，不打断正在进行的排查。
07 / AGENT ACCESS
痛点：突然接手一台陌生服务器，AI 却没有连接条件

快速给临时接手的服务器，对接上可控的 AI 运维能力。

传统做法要求本机提前拥有每台服务器的 SSH 凭证。但服务器一多，很难全部配置本地密钥；很多环境也不允许这样做。临时接手他人的服务器时，AI 无法直接帮助搜集日志和分析环境。

OpsCopilot 怎么解决

CLI 复用用户已经保存在 GUI 中的连接配置和登录凭据，Codex、Claude Code、Cursor 可通过 Skill 快速接入远程执行、知识诊断和文件操作，无需再为 Agent 单独配置一套 SSH 凭证。

凭据复用

GUI 能登录的服务器，可以快速接上 Agent 能力。

权限控制

IP / CIDR、命令、文件路径、大小、超时和输出统一受控。

完整差异化能力

从复杂连接到 AI 运维，
覆盖完整现场。

围绕复杂连接、多终端协作、知识驱动定位、业务脚本复用和 Agent 安全接入，OpsCopilot 提供一套连续的增强能力。SSH 终端、会话保存、搜索、上传下载、主题、设置、Keyring 与更新回滚等基础能力同样完整支持。

基础能力一句话：你对成熟远程终端、会话管理、文件管理、快捷命令、脚本管理、安全存储和应用维护的常规预期，OpsCopilot 都具备。

复杂连接与现场组织 CONNECT

  • Telnet 自动登录识别登录提示、回填凭据并协商终端窗口。
  • 自然语言连接解析从一段描述中提取主机、账号、协议、端口和 IP 范围。
  • 跳板机与自动提权穿透跳板机后继续切换目标用户，减少机械登录步骤。
  • 跳板机模板把重复使用的多层连接流程保存为可复用配置。
  • 多节点批量连接一次打开同一业务集群中的多个目标节点。

多终端效率 TERMINAL

  • 自由拖拽分屏按任务把多个标签分组、并排或折叠。
  • 广播输入将同一输入同步发送到选定终端。
  • Linux 智能补全补全命令及参数，减少记忆和输入成本。
  • 自然语言生成命令用 Ctrl+K 描述意图并保留生成历史。
  • 跨行规则高亮正确处理中文、软换行和跨行日志模式。
  • 时间戳解析选中日志时间即可快速理解对应时刻。

受限环境文件处理 FILES

  • 三级传输降级SFTP 不可用时自动尝试 SCP 与 Base64，并进行 MD5 校验。
  • 批量与范围选择一次选择多项文件并统一传输。
  • 覆盖保护覆盖前自动备份，目标目录不存在时自动创建。
  • SSH 会话中继Root 无法直连时复用已有 SSH 会话完成文件操作。

有依据的 AI 定位 AI

  • 快慢模型分工简单任务和复杂推理分别选择合适模型。
  • 内部知识问答只围绕企业知识库回答具体运维问题。
  • Agent 自主检索自动搜索、阅读并组合多份相关经验。
  • 实时检索轨迹展示当前阶段、关键词、阅读文档和分析进度。
  • 结构化定位步骤把分析结果组织成可验证的排查顺序。
  • 命令来源验证建议命令必须有知识依据，无知识时不猜测。
  • 结论辅助生成帮助整理根因、解决方案和最终结论。
  • 文件行号回溯每条关键建议可以回到原始文档位置。

定位经验闭环 KNOWLEDGE

  • 终端时间线记录同步保留输入、输出和关键事件发生顺序。
  • 事件补充与修订现场中随时增加、编辑或删除排查节点。
  • 根因与方案整理把零散判断归纳为可读结论。
  • 结构化 Markdown生成便于版本管理和长期保存的知识文件。
  • 多级知识索引按服务、模块和故障场景组织经验。
  • 六维全文搜索从现象、组件、关键词等多个维度定位记录。
  • 归档立即可检索新经验保存后马上进入 AI 的检索范围。
  • Git 补丁共享以补丁方式在团队之间同步知识变更。
  • 失败暂存与重试同步失败时保留现场并支持一键恢复。
  • 质量与状态跟踪通过评分、Issue 和状态管理知识生命周期。

业务脚本复用 AUTOMATE

  • 操作录制成脚本把一次真实终端操作转成可复用步骤。
  • 步骤插入与启停按需要调整顺序或临时跳过某一步。
  • 变量化输入用占位符适配不同节点、服务和环境。
  • 在线会话回放选择已连接会话直接执行脚本流程。
  • 导出 Bash将整理后的流程带到其他工具继续使用。

外部 Agent 接入 AGENT

  • GUI 与 CLI 同包一个可执行文件同时服务人工和 Agent。
  • 受控远程执行通过 exec 命令在策略内执行远端操作。
  • 只读知识诊断通过 diagnose 获取不接触服务器的分析结果。
  • 受控文件传输通过 file 在限定路径和大小内处理文件。
  • 连接自动自愈会话失效时尝试恢复，并明确返回 warnings。
  • 多 Agent Skill支持 Codex、Claude Code 与 Cursor 快速接入。
  • 多个 Skill 目录适配同机存在多个 Agent 工作环境。
  • Skill 状态检测识别未安装、过期与需要更新的接入配置。
  • Skill 版本同源内嵌发布，避免 CLI 与操作说明版本错位。
  • 共享运维内核Agent 复用 GUI 的连接、凭据与安全规则。

Agent 安全边界 GUARDRAILS

  • IP / CIDR 白名单按服务器与网段定义允许执行的命令范围。
  • 策略实时预览配置时直接看到目标会命中哪一条规则。
  • 文件访问策略限制远端路径、文件大小和拒绝规则。
  • 执行约束与审计统一控制超时、输出、空闲断连并记录操作意图。

我们不会收集你执行的命令、脚本内容、文件名和路径、服务器信息、终端输出、AI 对话或知识文档，也不会收集密码、令牌等凭据。数据发送至内网服务器，不涉及任何形式的外发。

客户端会在首次启动时说明完整的采集范围和保存期限，再由你选择是否同意。你可以拒绝上报，也可以接受只包含每日使用情况、客户端版本，以及用于避免重复统计的随机编号的最简方案，并随时在设置中关闭上报。

拒绝上报不影响正常使用。共享知识库和共享连接信息仍按各自的配置和权限运行。
